生成前必须确认的几项设置

项目建议值说明
Project Name / Location 纯英文、无空格，如 D:\Dev\F407_LED 中文路径是各种诡异报错的根源
Toolchain / IDE CMake 用 VS Code 开发就选它；也可选 Makefile 或 CubeIDE
Code Generator 勾选 Copy only the necessary library files 只拷贝用到的库文件，工程体积更小
Firmware Package 用已下载的最新版本 列表为空说明固件包未安装，请返回第三章完成下载
关于 .ioc 文件：它是工程配置的“源头”，双击即可回到 CubeMX 修改配置，改完后再生成一次代码；它应与源码一起提交到 Git。自行编写的代码放在 /* USER CODE BEGIN */ 与 /* USER CODE END */ 之间，重新生成时不会被覆盖。
