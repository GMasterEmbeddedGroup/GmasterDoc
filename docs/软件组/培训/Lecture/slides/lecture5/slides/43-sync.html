fetch、pull 与 push

先理解数据方向，再运行同步命令。

命令方向是否改当前分支
git fetch upstream远程 → 本地远程跟踪引用否，适合先查看
git pull upstream main获取后整合到当前分支是
git push -u origin branch本地分支 → 远程设置后续默认跟踪关系
$ git fetch upstream
$ git log --oneline main..upstream/main
$ git switch main
$ git merge --ff-only upstream/main
pull 不是“下载一下”。它会获取并整合；工作区有未提交修改时，先处理当前工作。
