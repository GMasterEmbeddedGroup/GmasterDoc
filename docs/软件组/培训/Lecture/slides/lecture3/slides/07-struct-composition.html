数组、嵌套与结构体指针

结构体可以像其他类型一样组合。

typedef struct { float x, y, z; } Vec3;
typedef struct {
    uint8_t id;
    Vec3 gyro;
} ImuSample;

ImuSample samples[16];
ImuSample *p = &samples[0];

samples[0].gyro.z = 1.25f;
p->gyro.z = 1.25f;       // 等价于 (*p).gyro.z
对象sample.member
→
对象的地址&sample
→
结构体指针p->member
参数较大时：传 const ImuSample *sample，避免复制整个结构体，也表达函数不会修改它。
