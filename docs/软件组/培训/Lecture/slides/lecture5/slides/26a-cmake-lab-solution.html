CMake 练习答案

答案把 calc 建成独立库。app 只列自己的 main.c，再通过链接取得 calc 的实现和公开头文件路径。

顶层 CMakeLists.txt
cmake_minimum_required(VERSION 3.20)
project(calc_demo LANGUAGES C)

add_subdirectory(lib)
add_executable(calc_demo src/main.c)
target_link_libraries(calc_demo
    PRIVATE calc
)
lib/CMakeLists.txt
add_library(calc STATIC calc.c)

target_include_directories(calc
    PUBLIC ${PROJECT_SOURCE_DIR}/include
)

target_compile_features(calc
    PUBLIC c_std_11
)

为什么这样能工作

add_subdirectory 先创建 calc；app 链接 calc 后，CMake 安排构建顺序。PUBLIC 头文件路径沿依赖关系传给 app，所以 main.c 能找到 calc.h。

验证：cmake -S . -B build -G Ninja，再运行 cmake --build build 和生成的程序，输出应为 2 + 3 = 5、5 - 3 = 2。
