CMake 排错与课堂练习

先读第一条真正的错误，再判断属于配置、编译还是链接。

找不到源文件

检查相对路径以当前 CMakeLists 所在目录为基准；检查大小写和文件是否已保存。

找不到头文件

检查 include 路径是否挂到正确目标，作用域是否覆盖使用者。

undefined reference

声明已找到但实现没有链接进来；检查源码所属库和 target_link_libraries。

练习：把 starter 演进为两目标工程

  1. 配置、构建并运行 starter。
  2. 创建 calc.h 与 calc.c，实现 add_int。
  3. 把 calc 建成静态库，让 app 链接它。
  4. 重新构建，输出 2 + 3 = 5。
