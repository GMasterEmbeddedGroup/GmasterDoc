等级 3：按键外部中断

中断只记录事件，主循环负责切换灯效，避免在 ISR 里做复杂工作。

static volatile bool button_pending;

void HAL_GPIO_EXTI_Callback(uint16_t pin) {
    if (pin == USER_BTN_Pin) button_pending = true;
}

while (1) {
    if (button_pending) {
        button_pending = false;
        led_mode = (led_mode + 1) % LED_MODE_COUNT;
    }
    led_update();
}
按键抖动：一次按下可能产生多个边沿。可在主循环中用时间戳消抖，或用定时器在边沿后延迟采样；不要在中断里 HAL_Delay。
