数组、结构体与多结果接口

函数只能返回一个值；结果不止一个，或者对象较大时，用输入指针加输出指针的接口。

typedef struct { int min; int max; } Range;

void measure_range(const int data[], size_t count, Range *out) {
    out->min = data[0];
    out->max = data[0];
    for (size_t i = 1; i < count; ++i) {
        if (data[i] < out->min) out->min = data[i];
        if (data[i] > out->max) out->max = data[i];
    }
}

data 只读，用 const 说明函数不会修改它；out 指向调用方准备的结果位置。
