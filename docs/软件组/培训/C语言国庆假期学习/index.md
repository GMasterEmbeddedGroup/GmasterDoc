# 国庆假期学习

## 国庆假期作业

本次假期作业均需完成：

1. **洛谷新增作业**：[P5740「最厉害的学生」](https://www.luogu.com.cn/problem/P5740)和 [P5744「培训」](https://www.luogu.com.cn/problem/P5744)，[B4060「位运算」](https://www.luogu.com.cn/problem/B4060)（完整题单见gmaster洛谷团队作业） 完成后保留通过记录；
2. **点灯大师**：按照[点灯大师教程](../Lecture/点灯大师.md)完成板载 LED 点亮、程序烧录和外接 LED 练习，保留可编译的工程与演示结果；
