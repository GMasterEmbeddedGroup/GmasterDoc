基本数据类型

C 语言的数据类型一共只有几个，先把用在单片机上的这几类记熟。下表是 32 位平台上最常见的大小。

类型典型大小取值范围典型用途
char1 字节-128 ~ 127单个字符、很小的整数
unsigned char1 字节0 ~ 255原始字节数据（串口、CAN 报文）
short2 字节-32768 ~ 32767够用就好时比 int 省内存
int4 字节-21 亿 ~ 21 亿最常用的整数类型
unsigned int4 字节0 ~ 42.9 亿计数器、位运算掩码
long long8 字节约 ±9.2×1018计算总量、时间戳
float4 字节约 ±3.4×1038（6~7 位有效数字）传感器、PID 计算
double8 字节约 ±1.8×10308（15~16 位有效数字）需要更高精度的计算
大小不是绝对的：它由编译器与目标平台决定（STM32 上 int 是 4 字节， 某些 8 位单片机上只有 2 字节）。不要背，用 sizeof 量出来。 浮点数有效位数只有 6~7 位，机器人的姿态解算要小心精度损失。
