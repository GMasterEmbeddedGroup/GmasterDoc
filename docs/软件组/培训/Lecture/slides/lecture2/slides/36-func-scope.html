局部变量与作用域

变量在哪个花括号里定义，就只能在那个花括号里使用 —— 这个「可见范围」就是作用域。

scope.c同名变量互不干扰
int counter = 0;             /* 全局变量：所有函数都能访问 */
void tick(void)
{
    int step = 3;            /* 局部变量：只在 tick 里存在 */
    counter += step;
}

int main(void)
{
    int step = 100;          /* 与 tick 里的 step 互不干扰 */
    tick(); tick();
    printf("%d %d\n", counter, step);   /* 6 100 */
    return 0;
}
三个坑：① 局部变量没初始化就是随机值；② 函数返回后局部变量的内存被回收，不要返回它的地址； ③ 全局变量虽方便，但以后调试时很难查是「谁改了它」，能不用就不用。
