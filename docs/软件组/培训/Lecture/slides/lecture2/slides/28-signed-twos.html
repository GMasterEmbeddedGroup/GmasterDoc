负数怎么存：补码

8 位只有 256 种组合，却要同时表示正数和负数。C 语言（以及所有现代计算机）的做法是用一半组合表示负数。

符号1 641 321 161 81 41 21 11

最高位是 1 → 这是负数：1111 1111 就是 -1（而不是 255）。

无符号 unsigned
8 位全部用来表示大小：0 ~ 255。适合原始字节、掩码、计数器。
有符号 signed
最高位当符号位（1 = 负），范围变成 -128 ~ 127。默认的 int、char 都是有符号的。
补码怎么求
取反再 +1：5 是 0000 0101，取反得 1111 1010，加 1 得 1111 1011 = 0xFB。
为什么这么麻烦
用补码后减法可以交给加法电路做，硬件简单，而且只有一个 0。
经典 bug：把有符号数和无符号数混在一起比较时，编译器会把有符号数转成无符号， 于是 if (a - b > 0) 在两者都为 unsigned 时永远为真。
