函数指针

函数也有地址；函数指针让“调用哪段逻辑”变成可传递的数据。

typedef void (*EventCallback)(int event);

void on_button(int event) {
    printf("button: %d\n", event);
}

void dispatch(EventCallback cb, int event) {
    if (cb != NULL) cb(event);
}

dispatch(on_button, 1);
注册保存函数地址
→
事件发生timer / gpio / uart
→
调用cb(event)
回调的基础：“函数地址 + 约定好的参数与返回值”。
