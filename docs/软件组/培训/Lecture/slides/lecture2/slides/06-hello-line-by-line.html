逐行读懂这 6 行

点击左侧任意一行，右侧显示这一行的作用。每一行都不是可有可无的。

#include <stdio.h>

预处理指令

把「标准输入输出头文件」的内容原样抄到这一行的位置。它告诉编译器 printf 这个名字长什么样（参数、返回值），否则编译器根本不认识它。

凡是以 # 开头的都叫预处理指令，行尾不加分号。

int main(void)

主函数：程序的入口

操作系统从这个函数开始执行程序。int 是它的返回类型， (void) 表示它不接受任何参数。

一个程序有且只有一个 main，大小写敏感，Main 不算数。

{ }

函数体

一对花括号把「这个函数要做什么」括起来：函数体里的语句由大括号整体控制，必须成对出现。

大括号不配对时的典型报错是 expected declaration or statement at end of input（文件末尾少了一个 }）。

printf("Hello, World!\n");

函数调用

调用 printf 把双引号里的内容输出到屏幕。引号中的部分叫字符串。

后面讲输入输出时这行会再出现一次：%d 这类占位符可以把变量的值插进字符串。

;

语句结束符

分号表示「一条语句写完了」。C 语言用分号而不是换行来断句，所以一条语句可以写好几行， 但分号忘了写编译器一定报错。

最常见的报错 expected ';' before '}' token，通常就是上一行少写了分号。

\n

转义字符：换行

它不是一个真的反斜杠加 n，而是「换行」这一个字符。没有它，下次输出的内容会接在同一行后面。

类似的还有 \t（制表符）、\\（一个反斜杠）、\"（一个双引号）。

为什么「换行」会和「回车」分成两个词？下一页有一台还在工作的电传打字机给你演示。

return 0;

返回状态码

把 0 交还给操作系统，约定 0 表示正常结束，非 0 表示出错。其他程序（比如编译脚本）会读这个值判断你的程序有没有跑成功。

写 return 0; 是好习惯，尤其在机器人这类多程序协作的场景里。
