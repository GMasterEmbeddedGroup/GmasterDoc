动手练习：手工算一遍再让程序验算

先在纸上算出结果，再写程序输出正确答案对照 —— 这是最快掌握进制转换的方法。

练习要求怎么验算
1 把十进制 42、100、255 转成二进制与十六进制（手工完成） 程序里写 printf("%d %x\n", 42, 42); 对照
2 把 0b1011 0110 转成十进制与十六进制 写 int x = 0b10110110; 用 %d 与 %x 打印
3 写出 -1、-128 用 8 位二进制表示的形式（补码） 用 char c = -1; 打印 (int)(unsigned char)c
4 写程序：把变量 x 的第 3 位置 1、第 0 位清 0，其它位不变 先给 x = 0x00，期望得到 0x08
