## 国庆假期作业

本次假期作业均需完成：

1. **洛谷新增作业**：[P5740「最厉害的学生」](https://www.luogu.com.cn/problem/P5740)和 [P5744「培训」](https://www.luogu.com.cn/problem/P5744)，完成后保留通过记录；
2. **点灯大师**：按照[点灯大师教程](../Lecture/点灯大师.md)完成板载 LED 点亮、程序烧录和外接 LED 练习，保留可编译的工程与演示结果；
3. **Lecture 4**：阅读最新课件，并完成课件中的动手练习。

## 建议节奏

1. 先阅读“课程设计思想”，了解内存、函数和编译器三个视角，再进入“预处理”；
2. 配合 Lecture 4 学习，每天阅读一个小节，并把其中的示例手敲一次；
3. 遇到指针、`volatile`、链接等主题时，先画内存或调用关系，再回到代码验证；
4. 完成洛谷作业与点灯大师后，再检查代码、工程文件和通过记录是否齐全。
