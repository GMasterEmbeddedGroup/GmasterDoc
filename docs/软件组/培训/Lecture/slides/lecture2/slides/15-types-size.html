用 sizeof 量出真实大小

sizeof 不是函数，而是一个运算符：它在编译期就算出结果，不产生任何运行开销。

sizes.c自己动手量一遍
#include <stdio.h>

int main(void)
{
    printf("char   = %zu 字节\n", sizeof(char));
    printf("int    = %zu 字节\n", sizeof(int));
    printf("float  = %zu 字节\n", sizeof(float));
    printf("double = %zu 字节\n", sizeof(double));
    return 0;
}
占位符用 %zu：sizeof 的结果类型是 size_t（无符号），用 %d 打印会有警告。

为什么会「溢出」

char 的范围是 -128~127：char c = 127; c = c + 1; 不会得到 128，而是绕回到 -128。

为什么这很危险

机器人上这类 bug 很常见：编码器计数超出 short 范围后突然变成负数，电机随即反转。
