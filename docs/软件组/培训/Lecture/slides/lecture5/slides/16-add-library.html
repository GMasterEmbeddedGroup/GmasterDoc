add_library：创建库目标

库是有名字、有依赖、有使用要求的目标。

lib/CMakeLists.txt
add_library(calc STATIC
    calc.c
)

target_include_directories(calc
    PUBLIC ${CMAKE_CURRENT_SOURCE_DIR}/../include
)
目录
solution/
├─ CMakeLists.txt
├─ include/calc.h
├─ lib/
│  ├─ CMakeLists.txt
│  └─ calc.c
└─ src/main.c
STATIC 生成静态库。链接时，最终程序会取得它需要的代码。
