例子：12 字节怎样变成 7 字节

仍假设 uint32_t / uint16_t 的自然对齐为 4 / 2。

自然对齐：sizeof = 12

tag···value ×4crc ×2··

tag@0, value@4, crc@8；中间 3 字节、末尾 2 字节为填充。

1 字节 packing：sizeof = 7

tagvalue ×4crc ×2

tag@0, value@1, crc@5；没有填充，但 value 很可能落在非 4 字节边界。

_Static_assert(sizeof(GccPacket) == 7, "unexpected layout");
printf("%zu %zu %zu\n", sizeof(GccPacket),
       offsetof(GccPacket, value), offsetof(GccPacket, crc)); // 7 1 5
代价与边界：未对齐成员访问可能更慢，某些目标上甚至会触发异常；不要随意把 &p.value 交给要求自然对齐的指针。packing 也不会处理大小端、字段宽度或版本兼容，通信协议仍优先逐字段编解码。
