在电脑上编译运行 C 程序

Lecture 1 装的 arm-none-eabi-gcc 是给 STM32 用的交叉编译器，它生成的程序不能在 Windows 上运行。

还需要一个本机编译器（host 编译器）

它生成的程序能在你自己的电脑上跑，用来练语法、验证算法。三选一即可：

  • MSYS2：装完执行 pacman -S mingw-w64-ucrt-x86_64-gcc（推荐，附带 gdb 调试器）
  • WinLibs：下载 zip 解压，把 bin 目录加进 PATH
  • MSVC Build Tools：用 VS Code 的 C/C++ 插件自动识别

验证与运行

新开一个终端（改过 PATH 必须重开），依次输入：

> gcc --version gcc (MinGW-W64 x86_64-ucrt) 14.2.0 > gcc hello.c -o hello.exe > .\hello.exe Hello, World!

PowerShell 里运行当前目录的程序要写 .\ 前缀，只敲 hello.exe 会提示「无法识别」。

不要双击 exe 看结果：程序输出闪一下就没了。所有编译、运行都在 VS Code 的终端里做。
