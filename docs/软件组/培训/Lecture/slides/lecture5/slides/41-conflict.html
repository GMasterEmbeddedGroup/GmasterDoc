合并冲突的处理流程

冲突表示 Git 无法替你决定保留哪段内容，不代表仓库损坏。

冲突标记
<<<<<<< HEAD
option(ENABLE_TRACE "" OFF)
=======
option(ENABLE_TRACE "" ON)
>>>>>>> dev/trace

1. 定位

git status 列出 unmerged paths。

2. 编辑并验证

理解两边意图，删除标记，构建和测试结果。

3. 完成

git add file，然后 git commit 或继续 rebase。

不确定时先停下。使用 git merge --abort 回到合并前，再与改动作者确认。
