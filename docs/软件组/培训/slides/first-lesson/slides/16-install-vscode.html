第一步：安装 VS Code

官网 code.visualstudio.com，免费，Windows、macOS、Linux 都有。

01下载

选择 Windows x64 User Installer。用户版不需要管理员权限，注意不要下载 System 版或 ARM 版。

02安装

按默认选项安装即可，注意勾选 「添加到 PATH」和 「通过 Code 打开」这两个右键菜单项。

03汉化

按 Ctrl+Shift+X 打开扩展面板，搜索 Chinese (Simplified) 安装官方语言包，重启生效。

04两个习惯

开启「文件 → 自动保存」；用「打开文件夹」打开整个工程，而不是逐个打开文件，否则补全和跳转都无法工作。

本步仅完成代码编辑环境的搭建。将代码翻译为机器码的是 ARM GNU 工具链， 安装方法见 《Lesson1 开发环境配置》。
