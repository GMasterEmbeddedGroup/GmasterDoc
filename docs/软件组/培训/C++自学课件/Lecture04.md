## 内容大纲

| 章节 | 要点 |
| --- | --- |
| 逻辑与常识 | 命题、真假判断与逻辑推理 |
| 分支：`if ()` | 满足条件才做事 |
| 分支：`if () {…} else {…}` | 两种二选一的情况 |
| 分支：`else if` 链 | 多个条件依次判断 |
| `switch` / `case` / `break` / `default` | 多分支菜单式选择与穿透 |
| `while ()` 循环 | 条件为真时反复执行 |
| `do {…} while ()` 循环 | 至少执行一次的循环 |
| `for () {…}` 循环 | 初始化、条件、步进三部分紧凑写法 |
