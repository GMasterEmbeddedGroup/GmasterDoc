自编练习：只用指针

本题不依赖在线评测，直接在本机用断言验收。

void swap_int(int *a, int *b);
void reverse(int *first, int *last);       // [first, last)
const int *max_element(const int *first,
                       const int *last);

限制禁用下标

函数体内不能出现 []，只能移动和解引用指针。

边界空区间

first == last 时，max_element 返回 NULL。

验收断言

覆盖 0、1、偶数、奇数长度，以及含重复最大值的数组。

进阶：把比较规则改为函数指针，做一个通用的 max_element_by。
