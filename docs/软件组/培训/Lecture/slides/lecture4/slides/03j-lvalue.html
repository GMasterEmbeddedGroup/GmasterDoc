左值与右值

能取地址、能被赋值的是左值；只表示一个计算结果的是右值。

int a = 3;        /* a 是左值：有确定的内存位置 */
int b = a + 1;    /* a + 1 是右值：算完即止，没有地址 */

&a;               /* 合法：左值有地址 */
/* &(a + 1); */   /* 非法：右值没有地址 */

a = 5;            /* 赋值左侧必须是左值 */
  1. 左值：指向一块存储的对象，例如变量、数组元素、结构体成员、*p 解引用。
  2. 右值：表达式的计算结果、字面量、函数返回值，只提供数值，不能出现在赋值左侧。
  3. 两个判据：赋值号左边必须是左值；& 只能作用在左值上——这条在后面讲指针时会反复用到。
