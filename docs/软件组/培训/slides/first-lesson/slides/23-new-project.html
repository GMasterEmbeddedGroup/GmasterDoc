新建工程：五步

以 STM32F407ZGTx 为例。点击左侧步骤逐步查看操作要点。

① 新建工程并选择芯片

进入 File → New Project，在左上角搜索型号（例如 STM32F407ZGTx）后双击选中。 型号写错一位，后面所有配置都要重做——先确认芯片丝印上的完整型号。

② 配置调试口与时钟源

SYS 里把 Debug 设为 Serial Wire，RCC 里把 HSE 设为 Crystal/Ceramic Resonator。 不配调试口，首次烧录后可能无法再连接芯片；不配 HSE 则只能使用精度较差的内部时钟。

③ 配置引脚

在芯片图上左键点击要用的引脚，选择功能（例如 LED 引脚选 GPIO_Output），右键可以 Enter User Label 起个名字。 命名后生成的代码将使用该名称，而非 PA5 等默认引脚名。

④ 配置时钟树

切到 Clock Configuration，填入板载晶振频率（常见 8 MHz 或 25 MHz），再设置目标主频。 F407 最高 168 MHz，H7 可达 480 MHz。出现红字说明频率超限，需要重新调整分频。

⑤ 生成工程

切到 Project Manager：填写工程名与保存路径（纯英文），Toolchain 选择 CMake，然后点击 GENERATE CODE。 产物：一个可以编译的完整工程
