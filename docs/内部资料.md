# 内部资料（登录后可见）

战队有一部分资料不适合公开：服务器与设备账号、未定稿的设计、现场调试流程、组内排班等。
这些内容放在**私有资料区**，只有通过 CAF 登录、并且拥有对应权限的成员才能看到。

<div data-caf-gate data-src="/_private/fragments/公告.html"></div>

## 怎么进去

1. 点右上角的「登录」（或下面的按钮），跳转到统一认证中心 `auth.apoints.email`；
2. 用你的 CAF 账号登录并同意授权，浏览器会跳回本站；
3. 回到本站后，右上角会显示你的昵称，此时即可访问**你有权限的**内部目录。

<p><a class="caf-gate__btn" href="/_caf/login?rd=%2F_private%2F">前往内部资料区</a></p>

> 第一次访问某个组的内容时如果提示「缺少访问所需权限」，说明你的账号还没有被授予该组的
> 权限节点 —— 找管理组在官网后台（权限管理）给你加上即可，授权后最多 5 分钟生效。
