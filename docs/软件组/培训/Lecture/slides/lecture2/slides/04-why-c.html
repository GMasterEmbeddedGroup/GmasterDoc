为什么从 C 语言开始

机器人上每块 STM32 跑的代码，几乎都是 C / C++ 写的。

01离硬件最近

C 只比汇编高一层：一个变量对应内存里的一块空间，一条语句往往对应几条机器指令。 这让你能准确地知道「代码在硬件上做了什么」。

02机器人的通用语言

STM32 的 HAL 库、电机驱动、CAN 通信、裁判系统协议，官方例程与开源工程全部是 C。 看不懂 C，就看不懂车上的任何一行业码。

03工具链统一

Lecture 1 装的 GCC 工具链、CMake、OpenOCD 都是围绕 C/C++ 设计的。 在电脑上写 C，和在 STM32 上写 C，语法与命令是同一套。

本讲目标：不要求背下所有语法，只要求两件事 —— 能读懂一段 C 代码在做什么； 能自己写出程序、编译通过、跑出正确结果。
