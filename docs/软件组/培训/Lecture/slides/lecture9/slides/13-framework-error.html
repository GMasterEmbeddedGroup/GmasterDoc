基本思路：从误差看功率分配

先假设最朴素的方案——每个轮向电机各自做速度 PI 闭环，再看它会出什么问题。

① 正常情况某个轮组被其他轮组牵引着运行，或者它牵引其他轮组运行时，该轮组的轮向电机当前实际转速与目标转速可以保持一致。
② 于是 error≈0误差近乎为零，控制系统输出不会改变，会维持当前输出。
③ 但输出并不合理对于牵引 / 被牵引的轮向电机，纯靠这个输出的扭矩（电流），要么无法驱动该轮组达到目标速度，要么早已满足驱动该轮组达到目标速度所需电流。
④ 极端例子四个轮向电机，三个输出都是 0 W，只有一个输出远高于驱动自身所需的功率——这种情况下，底盘照样能绕着轴旋转，达到想要的运动状态。
实测结论：在底盘到达目标运动状态的前提下，功率分配不均所消耗的总功率，大于功率分配均匀所消耗的总功率。这一点也可以从数学上推导出来。
