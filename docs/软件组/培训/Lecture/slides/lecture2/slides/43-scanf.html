scanf：把键盘输入读进变量

和 printf 正好相反：printf 把值送出去， scanf 把值读进来 —— 所以它需要知道变量在哪里。

input.c注意那个 &
#include <stdio.h>
int main(void)
{
    int n = 0;
    printf("请输入一个整数：");   /* 提示语不加 \n，让输入跟在后面 */
    scanf("%d", &n);              /* & 取地址：把值写到 n 所在的内存 */
    printf("%d 的平方是 %d\n", n, n * n);
    return 0;
}

为什么必须加 &

scanf 要直接改写那块内存，光知道「值是多少」不够，得知道「存在哪儿」。

数组名本身已经是地址，所以读字符串不加：scanf("%s", name);

一次读多个值

scanf("%d %d", &a, &b); 可以输入 3 5，也可以分两行。

格式串里不要加 \n，否则程序会一直等你再输入；要求输入整数却敲了字母时，scanf 会失败并留下垃圾数据。
