作用域：名字在哪里可见

变量定义在哪个花括号里，就只能在那个花括号内使用。

块作用域

int counter = 0;      /* 文件作用域 */

void tick(void) {
    int step = 3;     /* 只在 tick 内可见 */
    counter += step;
}

同名遮蔽

int step = 100;       /* 外层变量 */

void f(void) {
    int step = 3;     /* 遮蔽外层同名变量 */
    printf("%d\n", step);   /* 输出 3 */
}
文件作用域：在所有函数之外定义的变量，整个 .c 文件都能访问；要让其他文件使用，需要在头文件里声明（见 extern 一节）。名字够用就好，遮蔽合法但容易看错。
