函数的定义、声明与调用

一个函数由四部分组成：返回类型、函数名、参数列表、函数体。写好了就能像 printf 一样被调用。

add.c最简单的函数
#include <stdio.h>
int add(int a, int b) { return a + b; }   /* 函数定义 */
int main(void)
{
    printf("3 + 5 = %d\n", add(3, 5));    /* 函数调用 */
    return 0;
}
执行顺序：进入 main → 遇到 add(3, 5) 跳进去执行 → return 带回 8 → 继续执行下一行。
返回类型
函数交回什么类型的结果；不返回任何值就写 void。
参数列表
外部要提供的数据，每个参数都要写类型。
函数体
花括号之间的语句；遇到 return 立刻结束。函数必须先出现过再调用。
