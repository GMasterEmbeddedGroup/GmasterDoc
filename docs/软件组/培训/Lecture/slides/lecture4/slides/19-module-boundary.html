static 与 extern 划分模块边界

模块只公开外部需要的功能，具体实现留在自己的 .c 文件里。

motor.c

static int retry_count;

static void reset_bus(void) {
    retry_count = 0;
}

int motor_start(void) {
    reset_bus();
    return 0;
}

motor.h

#ifndef MOTOR_H
#define MOTOR_H

int motor_start(void);

#endif

static 让 retry_count 和 reset_bus 只在 motor.c 内可见。其他文件通过头文件调用 motor_start，但不需要知道它内部怎样复位总线。
