origin 与 upstream

远程名只是本地别名，必须看 URL 才知道它指向哪里。

$ git remote -v
origin git@github.com:alice/GSRL.git (fetch)
origin git@github.com:alice/GSRL.git (push)
upstream git@github.com:popchutty/GSRL.git (fetch)
upstream git@github.com:popchutty/GSRL.git (push)

origin

你克隆的 Fork；你有权限把开发分支推到这里。

upstream

原始项目；用于取得主线更新，最终通过 PR 合入。

$ git remote add upstream https://github.com/popchutty/GSRL.git
