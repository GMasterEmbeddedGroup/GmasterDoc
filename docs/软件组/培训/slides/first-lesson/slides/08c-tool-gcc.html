工具详解：arm-none-eabi-gcc

负责"译"：把 C/C++ 源码翻译成芯片能跑的机器码。

01它是什么

ARM 官方的交叉编译套件：编译器 gcc、链接器 ld、objcopy、调试器 GDB，一整套。

02在工作流里干什么

在 x86 电脑上编出 Cortex-M 的机器码：.c → .o → .elf → .bin。

03关键操作

安装后把 bin 目录加入 PATH；命令行输入 arm-none-eabi-gcc --version 能输出版本号即成功。

04常见坑

装成普通 gcc（它编不出 ARM 指令）；PATH 没配好，CMake 报"找不到编译器"。

要点：电脑与单片机的指令集不同，必须使用交叉编译器生成目标代码。
