工具详解：STM32CubeMX

负责"配"：图形化配置芯片，自动生成初始化代码。

01它是什么

ST 官方的图形化配置工具，覆盖全系列 STM32，把寄存器配置变成点选操作。

02在工作流里干什么

选型号 → 配引脚、时钟树、外设 → 生成 HAL 初始化代码。.ioc 文件是全部配置的源头，改配置就重新生成。

03关键操作

注册并登录 myST 账号；先下载对应系列的固件包（F4 / H7）；Project Manager 里 Toolchain 选 CMake。

04常见坑

手写的代码没放在 USER CODE 区间，重新生成时被覆盖；固件包没下载导致无法生成工程。

要点：CubeMX 负责生成初始化代码，业务代码必须写在 USER CODE 标记之间。
