位、字节与存储单位

计算机里最小的数据单位是位（bit）；能存 0 或 1 两种状态。8 位组成 1 个字节（byte）。

1281 640 320 161 81 41 20 10

这 8 位的组合是 1001 1100，按每位权重相加： 128 + 16 + 8 + 4 = 156。红色格子就是「这一位是 1」。

1 位（bit）
只有 2 种取值：0 或 1，单位记作 b。
1 字节（byte）
8 位，能表示 28 = 256 种状态，单位记作 B。
K / M / G
1 KB = 1024 B，1 MB = 1024 KB（1024 = 210，不是 1000）。

n 位能表示多少种状态

2n 种：8 位 → 256 种；无符号范围是 0 ~ 2n-1。

几个常见规模

STM32F407 的 Flash 是 1 MB，SRAM 192 KB；一帧 CAN 报文数据段最多 8 字节 = 64 位。
