在代码里写出不同进制的数

C 语言允许你用四种进制写同一个整数，编译器看到的前缀不同、值完全相同。

bases.c同一个数，四种写法
#include <stdio.h>

int main(void)
{
    int a = 156;          // 十进制：直接写
    int b = 0x9C;         // 十六进制：前缀 0x
    int c = 0234;         // 八进制：前缀 0（2*64+3*8+4 = 156）
    int d = 0b10011100;   // 二进制：前缀 0b（GCC 扩展，C23 起成为标准）

    printf("%d %d %d %d\n", a, b, c, d);   // 都用十进制打印 → 156 156 156 156
    printf("%x  %o\n", 156, 156);          // 十六进制 9c，八进制 234
    return 0;
}
同一个数用不同进制字面量写出，值完全一样：进制只是「写给人看的形式」，内存里都是二进制。
两个坑：① 0b 是 GCC 扩展（C23 前不是标准 C），换编译器可能不被支持； ② 前缀 0 开头就是八进制，写 int n = 010; 得到的不是 10 而是 8。
