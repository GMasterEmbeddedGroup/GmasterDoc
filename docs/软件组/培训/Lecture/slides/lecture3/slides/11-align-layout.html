手算结构体布局

每一格代表 1 字节。假设 char / uint32_t / uint16_t 的大小与对齐分别为 1 / 4 / 2 字节。

顺序 A：通常占 12 字节

struct A {
    char tag;       // offset 0
    uint32_t value; // offset 4
    uint16_t crc;   // offset 8
};
0tag 1P 2P 3P 4V 5V 6V 7V 8C 9C 10P 11P

为什么空 3 格：tag 后下一空位为 1；value 必须从 4 的倍数地址开始，所以 1～3 填充。value 占 4～7，crc 占 8～9，尾部再补 2 字节到 12。

顺序 B：通常占 8 字节

struct B {
    uint32_t value; // offset 0
    uint16_t crc;   // offset 4
    char tag;       // offset 6
};
0V 1V 2V 3V 4C 5C 6tag 7P

为什么只补 1 格：value 占 0～3，crc 占 4～5，tag 占 6；总长 7 不是 4 的倍数，尾部补到 8。

图例：V = value，C = crc，P = padding。成员起点向上对齐，结构体总长再补成最大对齐量 4 的倍数。
