PA0 下降沿的完整响应链路

下面每一项都是可独立检查的环节，排错时从左到右定位中断在哪里停止。

PA0
1 变 0
→

映射 EXTI0

EXTI

→
Callback
用户逻辑
外设层EXTI 检测下降沿并置位 PR。IMR 必须允许该线产生中断。
内核层NVIC 必须使能 EXTI0_IRQn，并根据优先级安排 CPU 响应。
软件层EXTI0_IRQHandler 调用 HAL 处理函数，随后进入用户回调。
GPIO 电平变化不代表链路完整。GPIO 模式、AFIO 映射、EXTI 边沿、NVIC 和 IRQHandler 必须同时正确。
