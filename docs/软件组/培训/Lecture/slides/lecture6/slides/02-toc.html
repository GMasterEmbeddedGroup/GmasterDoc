目录：GPIO 原理到外部中断

70 页按照参考讲座的大纲展开，并把 STM32F103 的系列差异和中断链路补充完整。

01 GPIO 基础GPIO 定义、端口与引脚、电平、电流、原理图、板载 LED、按键、上下拉和消抖。
02 八种模式浮空、上下拉、模拟输入，推挽、开漏与复用输出，以及输出速度和选型方法。
03 F103 寄存器CRL/CRH、IDR/ODR、BSRR/BRR 和 AFIO。明确区别于较新系列的 MODER/PUPDR。
04 CubeMX 与 HAL图形化配置、生成代码、初始化结构体、读写 API 和低电平有效封装。
05 系统中断轮询、ISR、向量表、NVIC、EXTI、AFIO 路由、HAL 回调、消抖与完整排错。
阅读顺序：模式解释引脚怎样工作，寄存器解释硬件怎样保存配置，中断解释边沿怎样让 CPU 执行代码。
