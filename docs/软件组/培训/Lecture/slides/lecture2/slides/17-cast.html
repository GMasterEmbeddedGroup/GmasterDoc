类型转换：整数除法是最经典的坑

不同类型混在一起运算时，编译器会先「统一类型」再计算。这一步往往是新手最容易出错的地方。

cast.c看得见的差异
#include <stdio.h>
int main(void)
{
    printf("%d\n", 5 / 2);            // 两边都是整数 → 整除，结果是 2
    printf("%.2f\n", 5.0 / 2);        // 有一个是浮点 → 结果是 2.50
    printf("%.2f\n", (float)5 / 2);   // 强制转换：(float)5 变成 5.0
    return 0;
}
写除法前先问一句：「我希望结果是小数吗？」如果是，至少有一个操作数要是浮点。
隐式转换
小转大安全；大转小可能丢数据，编译器通常只给警告。
显式转换
写法 (目标类型)表达式，只改变这一次运算的类型。
浮点数比较
不要写 if (a == 0.1)，应写成 fabs(a - 0.1) < 1e-6。
