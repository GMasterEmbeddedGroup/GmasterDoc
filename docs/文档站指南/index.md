# 文档站指南

本指南面向战队所有成员，教你如何参与 GMaster 文档站的建设与维护。

文档站基于 [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) 构建，托管于 GitHub，采用 PR 工作流协作。无论你是软件组、硬件组、机械组、视觉组还是宣运组的成员，都可以按照本指南贡献内容。

- [MkDocs 介绍与配置](./mkdocs介绍与配置.md) — 文档站技术栈、文件结构、如何新增页面与修改导航
- [Markdown 语法速查](./markdown语法.md) — 标题、图片、链接、代码块、引用、表格等常用语法
- [Git 工作流](./git工作流.md) — 如何 Fork、Clone、提交 PR，参与协作开发
- [登录与权限](./登录与权限.md) — 怎么登录、能看到什么、组别权限是怎么自动发的
- [网站完整架构](./网站完整架构.md) — CAF 认证中心 / 官网 / 文档站三套系统的全貌与运维速查
- [文档规范](./文档规范.md) — 如何写出清晰、可维护的技术文档
- [问题反馈](./问题反馈.md) — 如何提交 Issue 或联系作者
- [建站者说](./建站者说.md) — 文档站的由来与愿景
