多语句宏用 do { } while (0) 包装

调用处会在宏后面写分号，也可能把宏放进 if ... else，宏定义必须在这种写法下保持正确。

#define LED_ON() do {             \
    gpio_write(LED_PORT, LED_PIN, 1); \
    log_led_state(1);             \
} while (0)

if (ready)
    LED_ON();
else
    report_error();

do { ... } while (0) 只执行一次，把多条语句组成一个整体；调用处的分号不会破坏 if ... else 的结构。
