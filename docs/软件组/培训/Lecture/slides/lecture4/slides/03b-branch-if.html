if 语句的组成部分

条件写在括号里，分支体跟在后面，else 负责兜底。

组成部分写什么说明
if (条件)比较、逻辑表达式或函数调用结果为 0 时跳过本分支；括号不能省略，判断相等写 ==
分支体{ ... } 或单条语句只有一条语句时花括号可省；统一加更安全
else if / else再给一个条件，或其余全部情况自上而下第一个成立的分支执行；不加大括号时 else 与最近的 if 配对
 
if (speed > 8000)     motor_stop();
else if (speed < 0)   speed = 0;
else                  motor_run(speed);
