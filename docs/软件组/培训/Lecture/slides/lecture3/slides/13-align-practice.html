自编练习：内存侦探

先写预测，再在电脑与 STM32 工程里各运行一次。

typedef struct { uint8_t a; uint32_t b; uint16_t c; } S1;
typedef struct { uint32_t b; uint16_t c; uint8_t a; } S2;
typedef struct { uint8_t a; uint16_t c; uint32_t b; } S3;

任务 1纸上推导

标出每个成员的 offset、填充位置和总大小。

任务 2程序验证

用 sizeof 和 offsetof 打印结果，解释差异。

任务 3数组观察

打印 &arr[0] 和 &arr[1]，验证步长等于结构体大小。
