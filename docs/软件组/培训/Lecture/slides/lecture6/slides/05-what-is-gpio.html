输入、输出与 GPIO

先区分信号方向，再理解 GPIO：方向永远站在 MCU 的角度描述。

输入 Input

外部电路决定引脚电压，MCU 只读取结果。例如按键、限位开关和传感器告警信号。

输入脚阻抗很高，几乎不主动提供电流；无人驱动时必须用上下拉确定默认状态。

输出 Output

MCU 内部电路主动决定引脚电平。例如 LED、芯片片选和驱动器使能信号。

输出能力有限，只适合逻辑信号和小电流负载，不能把 GPIO 当作电源。
