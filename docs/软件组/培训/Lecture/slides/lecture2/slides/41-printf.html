printf：把变量的值打印出来

调试程序最基本的手段。引号里的 % 是占位符，后面的参数会按顺序填进去。

格式符用于例子与输出
%d十进制整数（int）printf("%d", -42); → -42
%u无符号整数（unsigned）printf("%u", 4000000000u); → 4000000000
%f浮点数，默认保留 6 位小数printf("%f", 3.14); → 3.140000
%c单个字符printf("%c", 'A'); → A
%s字符串printf("%s", "GMaster"); → GMaster
%x十六进制（%X 为大写）printf("%x", 156); → 9c
%p地址（指针）printf("%p", &n); → 0x7ffd1a2b3c4d
%zusize_t（如 sizeof 的结果）printf("%zu", sizeof(int)); → 4
占位符必须和参数类型一致：用 %d 打印浮点数、用 %s 打印整数， 都会输出乱码甚至让程序崩溃 —— 编译器通常只给一个 -Wformat 警告，记得看警告。 另外 %o 是八进制，%% 用来输出一个百分号本身。
