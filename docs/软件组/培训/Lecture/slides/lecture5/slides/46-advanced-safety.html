进阶命令与安全边界

这些命令有价值，但必须先看状态、理解影响范围。

命令用途边界
git stash push -m "wip"临时收起未完成修改不是长期存档；恢复后仍要检查冲突
git rebase main把自己的提交重放到新基线不要随意重写他人依赖的共享历史
git push --force-with-lease推送经过 rebase 的个人分支仅用于确认过的分支；lease 会拒绝覆盖未知更新
git reflog查找本地引用移动记录误操作后的重要恢复线索
红线：不把 reset --hard、clean -fd、push --force 当作常规排错按钮。先保存现场并向维护者确认。
