工具详解：OpenOCD

负责"烧"与"调"：把固件送进芯片，还能打断点、单步、看变量。

01它是什么

开源的片上调试服务（Open On-Chip Debugger），在 GDB 和调试器硬件之间当桥梁。

02在工作流里干什么

通过 ST-Link 把 elf 烧进 Flash；同时开一个 GDB server，断点、单步、查看变量全靠它。

03关键操作

VS Code 的 STM32 扩展点"烧录"时后台就在调它；也可手动 openocd -f interface/stlink.cfg -f target/stm32f4x.cfg。

04常见坑

连不上先查接线与驱动；报 target 相关错误，多半是线序、共地或复位配置问题。

要点：OpenOCD 同时承担固件烧录与在线调试两项职责。
