目标是 CMake 的组织中心

目标代表最终要构建的东西。可执行程序和库都是目标，源码、头文件路径、宏和编译选项都是目标的属性。

app可执行目标
sourcesmain.c
includesinclude/
definitionsENABLE_TRACE
dependenciescalc
创建目标add_executable(app src/main.c) 告诉 CMake 最终需要一个名为 app 的程序。
补充要求target_... 命令把源码、路径、宏和选项绑定到 app，而不是污染整个目录。
声明依赖target_link_libraries(app PRIVATE calc) 表示先构建 calc，再把它链接到 app。
阅读方法：看到 target 开头的命令，先找第一个参数。它回答“这条设置属于哪个目标”。
