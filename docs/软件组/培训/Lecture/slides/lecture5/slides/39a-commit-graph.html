提交图与分支指针

提交不会存放在“分支文件夹”里。提交组成有向历史，分支只是指向某个提交的可移动名字。

创建分支并提交后
A---B                 main
     \
      C---D           dev/cmake-demo (HEAD)
git switch -c dev/...从当前提交 B 创建新指针，并让 HEAD 指向新分支。
git commit创建提交 C，只有当前分支向前移动；main 仍停在 B。
git switch mainHEAD 改为指向 main，工作区随之恢复成 B 对应的文件状态。
git merge dev/...把另一条历史整合进当前分支；因此“当前分支是谁”会改变合并方向。
查看真实图形：git log --oneline --graph --decorate --all。先看 HEAD 和分支标签，再判断提交属于哪条开发线。
