配置、生成与构建的边界

终端里的一条 cmake 配置命令内部包含“配置”和“生成”；随后才由 cmake --build 执行真正编译。

输入

CMakeLists.txt、Preset、工具链文件、用户传入的 -D 变量。

cmake -S . -B build

配置与生成

检测编译器，计算目标关系，写入缓存，并生成 Ninja 或 Make 的规则。

$ cmake -S . -B build -G Ninja
-- The C compiler identification is GNU 15.1.0
-- Configuring done
-- Generating done
-- Build files have been written to: .../build

生成结果

CMakeCache.txt、CMakeFiles/、build.ninja。此时通常还没有 app.exe。

cmake --build build

构建结果

编译目标文件并链接 app.exe；源码错误会在这一阶段出现。
