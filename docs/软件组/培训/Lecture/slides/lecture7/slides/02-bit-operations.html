复习：位运算与逻辑运算

4表达式 6u & 3u 和 6u && 3u 的值依次为？A. 1，1　 B. 2，2　 C. 2，1　 D. 1，2

查看答案与解析
C：2，1。110₂ & 011₂ = 010₂。逻辑与判断两侧是否均为非零，结果为 1。

5reg 为 uint32_t 普通变量。仅将 bit 3 清零，应执行？A. reg |= (1u << 3);　 B. reg = 0u;
C. reg ^= (1u << 3);　 D. reg &= ~(1u << 3);

查看答案与解析
D。左移得到目标位掩码，取反后与原值按位与，保留其余位。

6哪个条件能正确判断 reg 的 bit 5 是否为 1？A. (reg & (1u << 5)) == 1u
B. (reg & (1u << 5)) != 0u
C. (reg && (1u << 5)) != 0u
D. (reg | (1u << 5)) != 0u

查看答案与解析
B。掩码后的结果可能是 0x20，应判断非零。注：整数常量后缀 u 表示无符号，如 1u。
