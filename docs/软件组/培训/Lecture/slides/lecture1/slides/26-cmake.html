CMake 是什么

工程中 CMake 相关文件较多，先明确以下概念。

名词是什么在本工程里
编译器 把源码翻译成机器码 arm-none-eabi-gcc
构建系统 决定先编谁、后编谁，哪个文件变了要重编 Make、Ninja（CMake 自动生成）
CMake 用 CMakeLists.txt 描述工程，再生成构建脚本 CMakeLists.txt、CMakePresets.json
工具链文件 告诉 CMake 用哪个编译器、什么参数 cmake/gcc-arm-none-eabi.cmake
为什么不直接在终端敲 gcc？ 一是工程有几十上百个源文件，手敲命令不现实；二是改一个文件只应重编它和依赖它的部分；三是换芯片、换电脑时只改配置。

实际开发中很少需要直接编写 CMake 配置：CubeMX 已自动生成，VS Code 的 CMake 插件负责调用。需要明确的是：CMake 管构建，不管烧录。
