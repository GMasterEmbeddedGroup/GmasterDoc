位运算：直接操作每一位

配置寄存器、解析报文、生成掩码都要用它。这一页是嵌入式开发中使用频率最高的一组运算符。

bits.c点灯与熄灯
#define LED_PIN  5              // 第 5 位对应 PA5
uint16_t odr = 0x0000;          // 假装这是 GPIOA 的输出寄存器

odr |=  (1 << LED_PIN);         // 置 1：把第 5 位置为高电平，点亮 LED
odr &= ~(1 << LED_PIN);         // 清 0：第 5 位变低电平，熄灭 LED
odr ^=  (1 << LED_PIN);         // 取反：翻转第 5 位（闪灯时常用）
if (odr & (1 << LED_PIN)) {     /* 读某一位的实际状态：非 0 就是 1 */ }
HAL 库里的 HAL_GPIO_WritePin() / HAL_GPIO_ReadPin() 内部做的正是这几件事，只是帮你把细节包起来了。

两条万能公式

  • 把第 n 位置 1：x |= (1 << n);
  • 把第 n 位清 0：x &= ~(1 << n);
  • 取第 n 位：(x >> n) & 1
  • 连续 k 位掩码：x & 0x0F（低 4 位）

移位就是乘除 2 的幂

x << 1 相当于 x × 2，x >> 3 相当于 x ÷ 8。

无符号数右移补 0；有符号负数右移补什么由实现决定，所以不要对有符号负数右移。
