工具详解：CMake

负责"编排"：决定哪些文件参与编译、按什么规则链接。

01它是什么

构建"配方"生成器——读 CMakeLists.txt，生成 Ninja / Makefile，再调度编译器执行编译。

02在工作流里干什么

声明源文件、头文件路径、宏定义、链接脚本；CubeMX 可以直接生成 CMake 工程。

03关键操作

cmake -B build -G Ninja 配置，cmake --build build 编译；日常在 VS Code 里一键完成。

04常见坑

改了 CMakeLists 没重新配置；缓存异常时，删除整个 build 目录重新配置即可。

要点：GCC 完成具体编译，CMake 统一管理构建过程，日常只需维护 CMake 配置。
