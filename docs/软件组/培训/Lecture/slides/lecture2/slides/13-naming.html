标识符与关键字

变量、函数、结构体……凡是需要起名字的东西，用的名字都叫标识符。

语法硬规则（错了就编译不过）

  • 只能由字母、数字、下划线组成
  • 不能以数字开头：2speed ✗
  • 不能含空格或符号：motor-speed ✗
  • 区分大小写：speed 与 Speed 是两个变量
  • 不能和关键字重名：int、for、return……

工程约定（团队协作靠它）

  • 见名知意：motor_speed ✔　a1 ✗
  • 小写下划线用于变量与函数：chassis_power_limit
  • 全大写用于常量与宏：MAX_SPEED、PI
  • 避免拼音与英文混写，更不要用中文拼音缩写
C 语言关键字（常用） intcharfloatdouble voidifelsefor whileswitchcasebreak continuereturnstructconst staticsizeofunsignedenum typedefexternuniongoto
关键字不需要背：VS Code 会把它们标成特殊颜色。真正要背的是 C 关键字表里你经常用到的那十几个。
