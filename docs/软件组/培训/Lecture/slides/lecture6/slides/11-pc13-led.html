PC13 板载 LED：低电平点亮

LED 阳极通过限流电阻接 3.3 V，阴极接 PC13。GPIO 负责吸收电流。

PC13 = 0

3.3 V 经 LED、电阻和 PC13 流向 GND，LED 亮。

逻辑反相

PC13 = 1

LED 两端压差接近 0，LED 灭。

HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_RESET); // 亮
HAL_GPIO_WritePin(GPIOC, GPIO_PIN_13, GPIO_PIN_SET);   // 灭
HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);
低电平有效：建议封装 Led_Set(bool on)，避免业务代码反复记忆反相关系。
