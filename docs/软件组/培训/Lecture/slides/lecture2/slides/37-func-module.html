把代码拆到多个文件

当程序超过几百行，就按功能拆分：头文件放声明，源文件放实现，别人只需 #include 头文件就能用。

math_utils.h接口：告诉别人「有什么」
#ifndef MATH_UTILS_H          /* 防止同一个头文件被重复包含 */
#define MATH_UTILS_H
int clamp(int value, int low, int high);
#endif
math_utils.c实现：把函数体写在这里
#include "math_utils.h"
int clamp(int value, int low, int high)
{
    if (value < low)  { return low;  }
    if (value > high) { return high; }
    return value;
}
编译时把所有源文件一起交给 gcc：gcc main.c math_utils.c -o app —— 这就是 GSRL 里 bsp/、module/、task/ 的组织方式。
