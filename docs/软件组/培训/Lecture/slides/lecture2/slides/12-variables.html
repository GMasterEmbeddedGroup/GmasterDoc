变量：给内存里的一块空间起名字

程序要处理的数据都存在内存里，变量就是「内存地址」的别名。写变量名，编译器负责换算成地址。

variables.c声明 · 初始化 · 赋值
#include <stdio.h>
int main(void)
{
    int   team_number = 2026;     // 声明并初始化：类型 名字 = 初值;
    float motor_speed = 3.14f;    // 浮点数要带小数点
    char  grade       = 'A';      // 单引号里只能放一个字符

    team_number = 2027;           // 赋值：把右边的值写进左边这块内存
    printf("%d %.2f %c\n", team_number, motor_speed, grade);
    return 0;
}
变量三要素：类型决定占几个字节、怎么解释这些 0/1；名字用来引用它；值随时可以被新值覆盖。
未初始化的局部变量是随机值：int n; 之后直接 printf，可能打印出一串莫名其妙的大数； 而想定义「不可更改的量」，要用 const 或 #define。
