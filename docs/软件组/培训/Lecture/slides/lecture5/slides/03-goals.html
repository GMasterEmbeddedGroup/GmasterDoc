学习目标、环境与阅读方法

课程围绕同一个 calc_demo 项目展开：先让它能够重复构建，再把一次功能修改安全交给团队。

学完能够独立完成

CMake：读懂常见目标语句，从空目录配置和构建，把新源码或库接入工程，并根据报错阶段定位问题。

Git：检查改动、选择暂存内容、创建清晰提交，在任务分支开发，同步远程并解决简单冲突。

团队协作：区分 origin 与 upstream，推送个人分支，写出包含验证方法的 Pull Request。

$ cmake --version
$ git --version
$ gcc --version
$ ninja --version
Windows 路径建议：把示例复制到 D:/workspace/lecture5-demo 等不含中文和空格的目录，避免旧工具版本处理路径失败。
阅读方法：遇到命令时先看“执行前状态”，再看命令改变了什么，最后用输出确认结果。无需一次背下全部参数。
