回调函数

库在约定时机调用用户提供的函数，实现控制反转。

typedef void (*OnByte)(uint8_t byte);

void uart_set_callback(OnByte cb);

static void parse_byte(uint8_t byte) {
    // 用户逻辑
}

uart_set_callback(parse_byte);

签名必须一致

参数和返回值组成接口契约。类型不匹配会造成编译错误或未定义行为。

上下文看调用者

回调可能在中断、主循环或 RTOS 任务中执行，能做什么取决于调用上下文。

空值调用前检查

可选回调用 NULL 表示未注册，调用前必须判断。

区分：回调是一种软件设计方式；中断是硬件事件机制。两者经常连用，但并不等价。
