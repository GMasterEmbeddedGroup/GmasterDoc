中断服务函数的工作边界

ISR 只做必须立刻完成的事，把耗时工作交回主循环或任务。

可以快速收尾

读取并清除中断标志；保存少量数据；更新计数器；设置事件标志；唤醒任务。

避免阻塞与重活

HAL_Delay、长循环、大量打印、动态内存、等待锁，以及不可重入函数。

static volatile bool button_pending = false;

void HAL_GPIO_EXTI_Callback(uint16_t pin) {
    if (pin == USER_BTN_Pin) button_pending = true;
}

// 主循环中处理耗时工作
if (button_pending) {
    button_pending = false;
    handle_button();
}
volatile 的边界：它要求每次都访问内存，但不保证复合操作原子，也不能替代临界区或内存屏障。
