检测、转换与协议

协议规定字节顺序，代码按字节显式组装，避免依赖主机布局。

运行时观察

uint16_t x = 0x0102;
uint8_t first;
memcpy(&first, &x, 1);

puts(first == 0x02
     ? "little" : "big");

读取大端 16 位

uint16_t read_be16(const uint8_t *p) {
    return ((uint16_t)p[0] << 8)
         |  (uint16_t)p[1];
}
避免：*(uint16_t *)p 既依赖主机字节序，还可能违反对齐要求和有效类型规则。
