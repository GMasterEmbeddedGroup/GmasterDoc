版本要求与工程声明

顶层文件先确定 CMake 行为，再声明工程使用哪些语言。

cmake_minimum_required

必须放在顶层文件开头。版本写团队实际支持的最低版本，不要机械追最新。

project

启用指定语言并检测编译器。纯 C 工程写 LANGUAGES C，C/C++ 混合工程再加 CXX。

可读取的内置变量
message(STATUS "project = ${PROJECT_NAME}")
message(STATUS "source  = ${PROJECT_SOURCE_DIR}")
message(STATUS "build   = ${PROJECT_BINARY_DIR}")

参考：CMake 官方命令文档 cmake_minimum_required() 与 project()
