结构体类型、变量与成员

先写出“档案卡模板”，再创建一张具体的卡，最后用点号找到其中一栏。

motor.cC99 指定成员初始化
struct Motor {
    uint8_t id;
    float speed;
    float current;
};

struct Motor yaw = {
    .id = 1, .speed = 0.0f, .current = 0.0f
};

yaw.speed = 120.0f;

类型struct Motor

规定栏目及每栏类型，本身不是一台电机。

变量yaw

按模板分配内存，保存一台具体电机的数据。

成员yaw.speed

点号左边是对象，右边是要访问的栏目。
