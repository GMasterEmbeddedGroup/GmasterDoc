「回车」和「换行」为什么是两个词？

为什么换行要写 \n？为什么它被叫作 newline，而另一个字符叫「回车」？ 答案在一百年前的电传打字机上。

B 站：《古代电传电报机作为 TTY 登录》（UP：有田兄）—— 一台还能用的老式电传打字机，敲键盘、走纸、回字车，全靠机械动作。
电传打字机
Teletype / TTY：键盘打字 → 电信号 → 对面那台一模一样的机器打印出来。它就是最早的计算机终端， Linux 里的 /dev/tty 至今还叫这个名字。
回车 CR
Carriage Return：把打字头（字车）推回行首。ASCII 13，C 里写 \r。
换行 LF
Line Feed：把纸向上滚一行。ASCII 10，C 里写 \n。
沿用至今的两个字符：Linux / macOS 用 LF（\n），Windows 用 CRLF（\r\n）， 老的 Mac 系统用 CR —— 这就是 Git 提示 LF will be replaced by CRLF、编辑器右下角写着 CRLF 的由来。 在 C 里写 "\n" 就是 LF。
