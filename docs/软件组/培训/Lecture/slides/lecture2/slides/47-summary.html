小结

这一讲把「写一个能跑的程序」所需要的全部基础件过了一遍。

01程序结构与编译

一个程序 = 预处理指令 + 函数；必须有 main。 源文件到可执行程序要经过预处理 → 编译 → 汇编 → 链接四步， 报错分编译期错误与链接错误两类。

02变量与数据类型

类型决定占几个字节和怎么解释这串 0/1。常用 char / int / unsigned / float / double， 大小用 sizeof 量。整数的溢出会「绕回」，是最危险的 bug 来源。

03二进制与进制转换

计算机只用 0/1，8 位 = 1 字节 = 256 种状态。 十进制 ↔ 二进制用「除 2 取余 / 按位权相加」，4 位二进制 = 1 位十六进制。 负数用补码表示，位运算直接操作每一位。

04函数与输入输出

函数把「一件事」封装起来，靠参数输入、靠返回值输出；参数是值传递。 printf / scanf 是调试与交互的基础工具， 格式符必须与参数类型一致。

下一讲预告：判断与循环（if / switch / for / while）→ 数组与字符串 → 指针与结构体 → 最后写一个能读串口数据的完整程序。 配套文档见 C++ 基础（C 与 C++ 语法通用）与 嵌入式基础。
