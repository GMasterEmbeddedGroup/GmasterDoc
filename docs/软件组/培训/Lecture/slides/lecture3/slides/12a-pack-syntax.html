两种 packing 写法如何工作

二者目的相似，但控制范围与可移植性不同；都不是 ISO C 标准语法。

#pragma pack：改变后续声明的状态

#pragma pack(push, 1)  // 保存旧值，最大对齐量设为 1
typedef struct {
    uint8_t  tag;
    uint32_t value;
    uint16_t crc;
} PragmaPacket;
#pragma pack(pop)      // 恢复旧值，避免影响别的结构体

pack(n) 把成员的有效对齐限制为“不超过 n”；push/pop 用来限定影响范围。具体支持的 n 由编译器决定。

packed：只标记这个类型

typedef struct __attribute__((packed)) {
    uint8_t  tag;
    uint32_t value;
    uint16_t crc;
} GccPacket;

这是 GCC / Clang 常见扩展，通常把该结构体及其成员的对齐需求压到 1；不会悄悄影响后续其他声明。

习惯：使用 pragma 时成对写 push/pop；跨编译器项目用条件宏统一封装，并用 sizeof / offsetof 验证布局。
