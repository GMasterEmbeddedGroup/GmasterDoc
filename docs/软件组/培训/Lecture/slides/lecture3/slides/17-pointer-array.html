指针与数组

在多数表达式里，数组名会转换为首元素指针。

int data[4] = {10, 20, 30, 40};
int *p = data;            // 等价于 &data[0]

data[2] == *(data + 2);  // 都是 30
p + 1;                   // 前进 sizeof(int) 字节
表达式含义常见误解
sizeof(data)整个数组的字节数，仅在数组仍是数组的作用域中成立不是指针大小
sizeof(p)指针变量本身的字节数不知道数组有几个元素
p[i]*(p + i)指针运算按所指类型缩放
边界：C 不检查下标。越过数组两端后再解引用属于未定义行为。
