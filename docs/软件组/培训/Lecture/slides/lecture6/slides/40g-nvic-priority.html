抢占优先级与子优先级

STM32 的优先级数值越小，优先级越高。数值 0 表示最高可编程优先级。

抢占优先级

更高的抢占优先级可以打断正在执行的低优先级 ISR。它决定能否发生中断嵌套。

A 的抢占值为 2，B 为 3，则 A 可以抢占 B。

子优先级

两个中断的抢占优先级相同时，子优先级决定谁先响应。它不能让二者相互打断。

A 为 2/1，C 为 2/0；二者同时等待时 C 先执行。

HAL_NVIC_SetPriority(EXTI0_IRQn, 2, 0);
HAL_NVIC_EnableIRQ(EXTI0_IRQn);
优先级分组决定可用位怎样分给抢占优先级和子优先级。HAL 工程通常在 HAL_Init() 中设置一次，模块不应反复修改。
