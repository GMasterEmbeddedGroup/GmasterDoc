函数与模块练习

先判断数据在哪里，再决定接口怎么写。

void add_offset(int value, int offset) {
    value += offset;
}

int speed = 100;
add_offset(speed, 20);
  1. 调用以后 speed 的值是多少？为什么？
  2. 怎样改写接口，才能让调用以后 speed 变成 120？
  3. 如果这个速度只允许由 motor.c 修改，头文件里应该公开变量，还是公开函数？
查看参考答案

speed 仍是 100，因为 value 只是副本。改成 void add_offset(int *value, int offset)，调用时传入 &speed。模块外只需要调用一个公开函数，速度变量应当留在 motor.c 内。
