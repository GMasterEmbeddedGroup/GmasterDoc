CubeMX 配置流程

选择 STM32F103C8Tx 后，在 Pinout 页面配置 PC13、输入按键与 SYS 调试接口。

  1. PC13 设为 GPIO_Output，标签设为 LED。
  2. 按键脚设为 GPIO_Input 或 GPIO_EXTI，选择匹配电路的 Pull-up/Pull-down。
  3. System Core → SYS → Debug 选择 Serial Wire。
  4. GPIO 参数中确认初始电平、输出推挽、速度和用户标签。
  5. 生成代码后检查 MX_GPIO_Init()，不要只相信界面。
先设置 LED 的安全初始电平，再把引脚切成输出，可减少上电瞬间闪烁或误动作。
