第四步：下载固件包

没有固件包，CubeMX 生成工程时会失败。这一步体积大，建议在实验室网络下完成。

01登录账号

进入 Help → Manage embedded software packages，按提示登录 myST 账号，没有就现场注册。

02下载对应系列

勾选你板子对应的系列：STM32F4（C 型板、F407）或者 STM32H7，点击 Install 等待完成。

03固件包位置

默认存在 C:\Users\<用户名>\STM32Cube\Repository，可以在 Help → Updater Settings 里修改。

04下载缓慢的处理

到官网手动下载固件包 zip，再用 From Local 从本地导入，可以绕开缓慢的在线下载。

固件包的内容是 HAL 库和 CMSIS 的全部源码，一个系列几百 MB。 它相当于芯片外设的说明书与参考实现，代码中的每一行 HAL_xxx() 最终都会调用其中的实现。
