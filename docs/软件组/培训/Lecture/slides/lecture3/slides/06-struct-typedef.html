typedef 与设计习惯

typedef 只创建类型别名，不创建新结构体。

常用写法

typedef struct {
    uint8_t r;
    uint8_t g;
    uint8_t b;
} RgbColor;

RgbColor warning = {255, 0, 0};

成员设计

  • 名字体现单位：speed_rpm
  • 协议字段用固定宽度类型：uint16_t
  • 硬件寄存器定义保留芯片手册中的命名
  • 初始化时优先写成员名，避免顺序改变后静默出错
注意：结构体赋值会复制所有成员。结构体里若保存指针，只会复制地址，不会复制指针指向的数据。
