每个工具只管一段路

「装好 VS Code 就能开发单片机」是常见误解。编辑器不是编译器，流程中的每个环节由不同工具负责。点击卡片查看各工具详解。

VS Code

负责代码编写：高亮、补全、跳转，本身不参与编译。

MX

CubeMX

负责硬件配置：图形化配置引脚与时钟，生成初始化代码。

GNU 工具链

负责编译：将源码翻译为芯片可执行的机器码。

CMake

负责构建组织：规定哪些文件参与编译、按什么顺序链接。

OCD

OpenOCD

负责烧录与调试：把固件写入芯片，支持断点调试。

STL

ST-Link

负责物理通道：USB 转 SWD 的硬件调试器。

PRG

CubeProgrammer

负责兜底烧录：官方工具，可擦除芯片、回读 Flash。

Git

负责版本管理：代码有历史、可回滚、可协作。

整体流程：VS Code 编写代码，CubeMX 生成配置，GCC 完成编译，CMake 组织构建，OpenOCD 与 ST-Link 完成烧录与调试，Git 管理版本。点击任意卡片查看对应工具的详细介绍。
