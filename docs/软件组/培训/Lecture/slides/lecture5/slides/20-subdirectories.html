add_subdirectory：拆分多目录工程

顶层文件描述模块关系，各子目录维护自己的目标。

顶层 CMakeLists.txt
cmake_minimum_required(VERSION 3.20)
project(calc_demo LANGUAGES C)

add_subdirectory(lib)
add_executable(app src/main.c)
target_link_libraries(app PRIVATE calc)
lib/CMakeLists.txt
add_library(calc STATIC calc.c)
target_include_directories(calc
    PUBLIC ${PROJECT_SOURCE_DIR}/include
)
target_compile_features(calc PUBLIC c_std_11)
顺序有意义：先进入 lib 创建 calc，再让 app 链接 calc。
