一条命令，四个步骤

平时只写 gcc hello.c -o hello，但编译器内部是按四步走的。点击左侧步骤查看每一步做了什么。

① 预处理：把 # 开头的都处理掉

#include <stdio.h> 把头文件内容原样展开， #define 做文本替换，#ifdef 决定哪些代码留下。 这一步只做文本拼接，不检查语法。 gcc -E hello.c -o hello.i

② 编译：C 语言 → 汇编

检查语法与类型，做优化，再把每条 C 语句翻译成对应 CPU 的汇编指令。 你能看懂的报错几乎都出在这一步，比如漏了分号、变量没定义、类型不匹配。 gcc -S hello.i -o hello.s

③ 汇编：汇编 → 机器码

汇编器把指令逐条翻译成 CPU 真正执行的二进制，得到目标文件。 此时还不能运行：函数地址没定下来，用到的库函数也还没加进来。 gcc -c hello.s -o hello.o

④ 链接：拼成一个完整程序

链接器把目标文件和标准库合并、解析函数地址，最后按链接脚本把代码与数据放到正确的位置。 在 STM32 上，这一步决定哪些代码进 Flash、哪些变量进 RAM。 gcc hello.o -o hello

报错分两类：error: ... 是编译期错误（语法写错了）； undefined reference to ... 是第 ④ 步的链接错误（函数只有声明，没有实现）。
