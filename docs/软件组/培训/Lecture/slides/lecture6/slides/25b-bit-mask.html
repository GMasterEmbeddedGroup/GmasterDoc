位、移位与掩码

一个 32 位寄存器同时保存多个引脚的配置，修改其中一部分时必须保留其他位。

uint32_t bit = 1u << 13;   // 只有 bit13 为 1
GPIOC->ODR |= bit;          // 把 bit13 置 1
GPIOC->ODR &= ~bit;         // 把 bit13 清 0

GPIOC->CRH &= ~(0xFu << 20); // 清 PC13 的 4 位
GPIOC->CRH |=  (0x2u << 20); // 写入新配置

1u << n 生成第 n 位掩码。按位或用于置位，和取反掩码用于清位。

直接写整个 CRH 会同时覆盖 PC8–PC15，可能破坏其他引脚。
