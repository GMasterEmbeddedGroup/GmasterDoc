message、if 与 option

用选项表达可切换功能，用消息显示关键配置。

CMakeLists.txt
option(ENABLE_TRACE "Print debug trace" OFF)

if(ENABLE_TRACE)
    message(STATUS "Trace enabled")
    target_compile_definitions(app PRIVATE ENABLE_TRACE=1)
endif()
$ cmake -S . -B build -DENABLE_TRACE=ON
-- Trace enabled
职责分开：option 定义用户配置，if 控制 CMake 语句，编译宏再传给 C 代码。
