字符输入输出与输入缓冲区

getchar / putchar 一次只处理一个字符， 是理解「输入流」最直观的工具。

count_chars.c统计一行里有多少个字符
#include <stdio.h>
int main(void)
{
    int c, count = 0;
    printf("输入一行文字，回车结束：\n");
    while ((c = getchar()) != '\n' && c != EOF) { count++; putchar(c); }
    printf("\n共 %d 个字符\n", count);
    return 0; }

缓冲区是什么

你敲的字符先攒在系统内存里，按回车才一起交给程序 —— 所以 scanf("%d") 读完后回车还留着。

于是出现经典现象

scanf("%d", &n) 后紧跟 scanf("%c", &c)，c 会读到残留的换行。

解法：scanf(" %c", &c);（前面加空格）或先 getchar(); 吃掉回车。
