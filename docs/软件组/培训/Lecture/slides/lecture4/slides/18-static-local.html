静态局部变量保留上一次调用的值

普通局部变量放在栈上，每次调用重新创建；加上 static 后落在 .data 或 .bss，只初始化一次，函数返回后依然存在。

unsigned int next_sequence(void) {
    static unsigned int sequence = 0;
    sequence += 1;
    return sequence;
}

/* 三次调用依次返回 1、2、3 */

适合保存只属于这个函数的少量状态，例如序号、一次性初始化标志、滤波器的历史值；其他函数看不到它。

注意：静态局部变量会让函数在相同输入下产生不同输出；中断或多线程调用时还要考虑并发保护。
