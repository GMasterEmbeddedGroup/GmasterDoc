volatile 的适用范围与边界

常见于外设寄存器、中断共享数据和 DMA 缓冲区；它只保证真实访问内存，不保证并发正确。

场景为什么需要它还要注意什么
外设寄存器硬件会自行改变状态位遵循芯片手册规定的读写顺序
ISR 与主循环共享标志中断可以随时写入标志复合操作是否原子
DMA 缓冲区DMA 绕过 CPU 改内存缓存维护、内存屏障和驱动约定
static volatile bool sample_ready;

void DMA_IRQHandler(void) {
    clear_dma_irq();
    sample_ready = true;
}
原子性：counter++ 由读、加、写三步组成，即使加上 volatile 也可能被中断插入；需要时使用临界区、原子操作或单写者设计。
