工具详解：VS Code

负责"写"：编辑器，不是编译器——它只让代码写得更舒服。

01它是什么

微软的免费开源代码编辑器。本体只做文本：高亮、补全、跳转、搜索，不含任何编译器。

02在工作流里干什么

代码编写的主要环境；通过 STM32 扩展把 CMake、GCC、OpenOCD 串成一键构建、一键烧录。

03关键操作

装中文语言包与 C/C++、STM32 扩展；Ctrl+` 打开内置终端；code --version 验证安装。

04常见坑

把编辑器的红波浪线当成编译错误；扩展装了没启用、改完配置不重建 IntelliSense。

要点：VS Code 只是编辑器，编译与烧录由背后的命令行工具链完成。
