等级 4：回调驱动的灯效

灯效模块只管理时间和状态，具体“亮灭动作”由调用者注入。

typedef void (*LedWrite)(bool on);

typedef struct {
    LedWrite write;
    uint32_t period_ms;
    uint32_t last_ms;
    bool state;
} Blinker;

void blinker_update(Blinker *b, uint32_t now) {
    if (now - b->last_ms >= b->period_ms) {
        b->last_ms = now;
        b->state = !b->state;
        b->write(b->state);
    }
}
这一页串起全讲：结构体保存状态，指针传递对象，函数指针实现回调，定时器或主循环提供时间事件。
