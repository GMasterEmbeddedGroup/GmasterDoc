课程主线：从电路走到代码

GPIO 同时属于硬件和软件。只学 API 会在接线错误时束手无策，只学电路又无法解释寄存器配置。

外部电路
电压、电流、电阻
→
引脚电路
输入、输出、保护
→
工作模式
推挽、开漏、复用
→
寄存器
CRL、IDR、BSRR
→
软件接口
CubeMX、HAL、EXTI

每一章都回答同一组问题：概念是什么，为什么需要，配置后电路怎样变化，代码怎样表达，配置错误会出现什么现象。

贯穿案例使用 Blue Pill 板载 PC13 LED 和一个外接按键。先用轮询确认硬件，再升级到外部中断。

阅读方法：遇到缩写先看本页或前一页的定义，不要跳过电气基础直接背八种模式。
