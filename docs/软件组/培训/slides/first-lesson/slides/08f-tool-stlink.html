工具详解：ST-Link

负责"通道"：USB 转 SWD 的硬件，电脑和芯片之间的物理桥梁。

01它是什么

ST 的调试器硬件——Nucleo 开发板上自带一个，也有独立版本可通过排针连接目标板。

02在工作流里干什么

提供 SWD 物理通道：只要 SWDIO、SWCLK、GND 三根线，就能烧录和调试。

03关键操作

装 ST-Link 驱动；固件过旧时用 CubeProgrammer 升级；接线先共地，再连信号线。

04常见坑

杜邦线接触不良（烧录成功率不稳定时优先排查）；固件版本过旧会无法识别新型号芯片。

要点：软件工具链必须经由 ST-Link 提供的 SWD 物理通道才能到达芯片。
