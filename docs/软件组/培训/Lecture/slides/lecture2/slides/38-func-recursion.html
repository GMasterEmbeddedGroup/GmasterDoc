递归：函数自己调用自己

递归不是炫技，而是「把大问题拆成同样形状的小问题」的写法。它必须有一个终止条件。

factorial.cn! = n × (n-1)!
#include <stdio.h>

int factorial(int n)
{
    if (n <= 1) { return 1; }        /* 终止条件：没有它就会无限递归 */
    return n * factorial(n - 1);     /* 把问题缩小一号，再交给自己 */
}

int main(void) { printf("5! = %d\n", factorial(5)); return 0; }
展开过程：factorial(5) → 5 × factorial(4) → 5 × 4 × factorial(3) → … → 5 × 4 × 3 × 2 × 1 = 120。

什么时候适合用

问题本身具有递归结构时：树的遍历（行为树！）、分治算法、汉诺塔、目录遍历。

什么时候不要用

每层递归都占栈空间（STM32 默认只有几 KB）。程序「跑着跑着就重启」时，先怀疑栈溢出。
