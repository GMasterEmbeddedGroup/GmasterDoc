Debug 与 Release

构建类型影响优化、调试信息和断言，不应靠手工拼编译参数。

单配置生成器

cmake -S . -B build/debug \
-G Ninja \
-DCMAKE_BUILD_TYPE=Debug
cmake --build build/debug

Ninja、Make 通常在配置时选择类型。

多配置生成器

cmake -S . -B build/vs
cmake --build build/vs \
--config Release

Visual Studio 通常在构建时选择类型。

调试先选 Debug。Release 优化后，变量可能被删除或执行顺序发生变化。
