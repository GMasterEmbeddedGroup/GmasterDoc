二进制 → 十进制：按位权相加

从右往左数，第 n 位的权重是 2n-1：1、2、4、8、16、32、64、128…… 把「这一位是 1」的权重加起来即可。

1281 640 320 161 81 41 20 10
128 + 16 + 8 + 4 = 156 位权： 1×128 + 0×64 + 0×32 + 1×16 + 1×8 + 1×4 + 0×2 + 0×1

几个必须一眼认出的值

  • 0b0000 0001 = 1　　0b0000 1111 = 15
  • 0b1000 0000 = 128　0b1111 1111 = 255
  • 0b1010 1010 = 170　0b0101 0101 = 85
  • 8 位全 1 = 255，就是把一个字节「用满」

两种方向都要熟练

正着算（二进制 → 十进制）：按位权相加，看寄存器里的位最常用；
倒着算（十进制 → 二进制）：除 2 取余，写掩码时最常用。

练到看见 0x9C 就能反应出 1001 1100，看硬件手册会快很多。
