scanf：把键盘输入读进变量

和 printf 相反：它要把值读进变量，所以必须知道变量在哪。

input.c注意那个 &
#include <stdio.h>
int main(void)
{
    int n = 0;
    printf("请输入一个整数：");   /* 提示语不加 \n，让输入跟在后面 */
    scanf("%d", &n);              /* & 取地址：把值写到 n 所在的内存 */
    printf("%d 的平方是 %d\n", n, n * n);
    return 0; }

为什么必须加 &

它必须知道「变量存在哪儿」—— 光知道值不够。

数组名本身已经是地址：scanf("%s", name);

一次读多个值

scanf("%d %d", &a, &b); 可以输入 3 5，也可以分两行。

格式串里不要加 \n；输入不是数字会失败并留下垃圾数据。
