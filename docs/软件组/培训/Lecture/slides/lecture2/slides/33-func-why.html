为什么要用函数

main 里把所有代码一路写下来当然能跑，但超过 50 行就会开始失控。

不拆函数的后果

  • 同一段计算在三个地方复制粘贴，改一处忘了另外两处
  • 想单独测一下「算平均值」这段逻辑，只能把整个程序跑起来
  • 出错时不知道该看哪一行，只能从头往下读

GSRL 的一个 main.c 只有几十行，其余全是函数调用。

函数带来的好处

  • 复用：写一次、调无数次，改一次就全部生效
  • 可读：clamp(speed, 0, MAX) 比一长串 if 自解释得多
  • 可测：给定输入、检查输出，不必启动整个程序
  • 分工：一人写电机控制，一人写通信，互不干扰
写好函数的三个原则：① 只做一件事，名字能概括它（20 行以内看完）； ② 需要的数据从参数传进来，不要偷读全局变量； ③ 结果通过 return 交回去，而不是直接打印。
