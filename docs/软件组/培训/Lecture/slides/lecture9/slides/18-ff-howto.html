需要哪些前馈

按物理来源拆开：主扭矩由动力学逆解算给出，小扭矩逐轮补——惯量、阻尼、摩擦、坡道、轮差。

前馈项算式（目标值 → 前馈量）为什么必须有参数从哪来
惯量\(m\dot{v}_{ref}\)、\(J\dot{\omega}_{ref}\)、\(J_w\dot{\omega}_{ref}\)目标在加速，扭矩必须先到位，否则只能靠 P 事后追建模 + 称重
粘性阻尼\(b\,v_{ref}\)、\(b_\omega\omega_{ref}\)阻力随速度线性增长，高速时占大头匀速爬行，记稳态电流
库仑摩擦\(\tau_c\,\mathrm{sgn}(\omega_{ref})\)与转向相反的常值阻力，低速最明显——也是静止时白耗功率的元凶正反转试验取半差
坡道 / 重力\(m g\sin\theta\)不补就溜坡，纯 P 追不回来IMU 俯仰角
轮间差异每轮自己的 \(k_i\omega_{ref}+\tau_i\)机械装得不理想，四轮出力不均、总功率偏大逐轮单独标定
① 目标速度 / 加速度 → 动力学逆解算 → 整车广义力 (F_x, F_y, T) ② 乘 Bᵀ 分出各轮扭矩 → 每个轮组再补：惯量 / 阻尼 / 摩擦 / 坡道 / 轮差
\[ \begin{pmatrix}\tau_1\\ \vdots\\ \tau_n\end{pmatrix}=B^{\top}\begin{pmatrix}F_x\\F_y\\T\end{pmatrix} \]

\(B\) 就是第 05 章正解算那个矩阵：速度是 \(v=B\,\omega\)，力就是 \(\tau=B^{\top}F\)（虚功原理，功率守恒），不用为力另推一套。

\[ \tau_i=\frac{s}{4}\left(\pm F_x\pm F_y+\frac{T}{a+b}\right) \]

上面是麦轮把 \(B_{\text{麦}}\) 展开后的样子；全向轮要换 45° 投影（出现 \(1/r\)），舵轮是 8 个轮向量、先算 \(v_0\) 再取模——三种底盘不能共用“除以四”。

工程上更常用实测标定：匀速爬行记录稳态电流，得到“阻力—速度”曲线直接查表——\(b\)、\(\tau_c\) 是装出来的，不是查出来的。
