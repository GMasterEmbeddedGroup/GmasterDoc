常量与字面量

程序里出现的「值」有两种写法：直接写出来的字面量，和起了名字的常量。

字面量
42、3.14、'A'（单引号）、"Hello"（双引号）—— 直接写死在代码里。
#define
预处理阶段做纯文本替换，没有类型、行尾不加分号：#define MAX_SPEED 8000。
const
只读变量：const int max_speed = 8000; 有类型、有作用域，写它赋值会直接报错。

该用哪个？

数值常量优先 const；跨文件共享的硬件地址、条件编译开关用 #define。

为什么不要写「魔法数字」

if (speed > MAX_SPEED) 一看就懂，调参数也只改一处。

约定：宏名与常量名全大写，单词间用下划线，如 WHEEL_RADIUS_MM。
