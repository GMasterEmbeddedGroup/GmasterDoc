HAL GPIO 读写 API

HAL 使用端口指针和引脚位掩码，标签宏可避免硬编码。

HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET);
HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
GPIO_PinState key = HAL_GPIO_ReadPin(KEY_GPIO_Port, KEY_Pin);

WritePin 使用 BSRR 原子写入；ReadPin 读取 IDR；TogglePin 适合单一执行上下文，复杂并发中应明确设定状态。

CubeMX 标签会在 main.h 中生成 LED_Pin 和 LED_GPIO_Port。
