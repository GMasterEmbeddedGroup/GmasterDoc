布尔值与真值

「真 / 假」的写法来自 19 世纪的布尔代数：布尔把逻辑推理写成 0 与 1 的运算，C 沿用了这个约定——0 为假，非 0 为真。

#include <stdbool.h>

bool ready = false;        /* bool / true / false：C99 */
bool same  = (count == 3); /* 比较结果：0 或 1 */
if (count) { }             /* 非 0 即真 */
  1. 比较与逻辑运算的结果是 int：成立为 1，不成立为 0；bool 只是这个约定的别名。
  2. 「真」不只有 1：if (-1)、if (0.1f) 都成立，判断条件时别写 if (x == 1)。
  3. 赋值也返回数值：if (x = 1) 是赋值、条件恒真，这是 = 与 == 混用后最典型的错误。
