CMakeLists.txt 的基本语法

CMake 使用“命令名(参数...)”的形式。换行主要用于排版，括号决定命令范围。

语法示例
# 井号开始单行注释
set(APP_NAME calc_demo)

add_executable(${APP_NAME}
    src/main.c
    src/report.c
)

message(STATUS "target=${APP_NAME}")
  1. 命令名通常写小写，便于保持统一风格。
  2. 参数由空白分隔；含空格的路径必须使用引号。
  3. ${NAME}读取变量；未定义变量通常展开为空。
  4. 相对路径以当前 CMakeLists.txt 所在目录为基准。
常见错误：把 C/C++ 语法带进 CMake，例如在行尾写分号，或使用 NAME=value 赋值。CMake 变量应使用 set(NAME value)。
