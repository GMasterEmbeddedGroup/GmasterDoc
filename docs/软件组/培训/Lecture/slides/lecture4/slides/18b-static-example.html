一个模块里的 static 写法

下面三处 static 都在同一份 motor.c 里，各自解决的问题不同。

/* motor.c */
static int retry_count;              /* 模块私有状态 */

static void reset_bus(void) {        /* 内部函数，只在本文件调用 */
    retry_count = 0;
}

unsigned int next_tick(void) {
    static unsigned int tick = 0;    /* 跨调用保留 */
    return ++tick;
}
  1. retry_count 不进入导出符号，其他文件的同名变量不会与它冲突。
  2. reset_bus 的参数和实现可以随时修改，不影响模块对外的接口。
  3. tick 不在栈上，中断和主循环同时调用 next_tick 时要单独考虑并发。
