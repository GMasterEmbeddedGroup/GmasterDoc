转义字符与输出对齐

在 % 和格式字母之间可以插入宽度与精度，让输出对齐，调试时一眼就能看出数据是否异常。

format.c宽度 · 精度 · 对齐
printf("|%d|\n", 42);          // |42|       默认宽度
printf("|%5d|\n", 42);         // |   42|    右对齐，宽度 5
printf("|%-5d|\n", 42);        // |42   |    左对齐
printf("|%05d|\n", 42);        // |00042|    用 0 补位
printf("%.2f\n", 3.14159);     // 3.14       保留 2 位小数（会四舍五入）
printf("%8.3f\n", 3.14159);    //    3.142   总宽 8，小数 3 位
printf("名字\t得分\n");        // \t 制表符，用来对齐表格
printf("路径：D:\\code\n");    // \\ 输出一个反斜杠
|42| | 42| |42 | |00042| 3.14 3.142 名字 得分 路径：D:\code
调试技巧：传感器数据一帧一帧刷屏时，用 printf("%6.2f %6.2f\n", ...) 让每列固定宽度，数值跳变一眼可见。
