IRQHandler 到用户回调

HAL 把硬件入口、通用处理和业务逻辑分成三层，便于多个引脚共用处理流程。

硬件 IRQHandler 调用 HAL 公用处理函数，随后进入用户回调
void EXTI0_IRQHandler(void)
{
  HAL_GPIO_EXTI_IRQHandler(GPIO_PIN_0);
}
void HAL_GPIO_EXTI_Callback(uint16_t pin)
{
  if (pin == GPIO_PIN_0)
    key_event = true;
}
HAL 处理函数已经检查并清除 EXTI 挂起标志。IRQHandler 中不要在调用它之后再次手动清除同一标志。
