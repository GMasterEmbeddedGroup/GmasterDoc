extern：声明与定义分开

extern 只声明名字和类型，不分配存储空间；存储由某一个源文件中的定义分配。

counter.h（声明）

#ifndef COUNTER_H
#define COUNTER_H

extern unsigned int can_rx_count;
unsigned int can_rx_count_get(void);

#endif

counter.c（定义）

#include "counter.h"

unsigned int can_rx_count;   /* 分配存储 */

unsigned int can_rx_count_get(void) {
    return can_rx_count;
}
头文件里不写定义：被多个源文件包含时会出现多份定义，链接阶段报 multiple definition。函数声明中的 extern 可以省略。
