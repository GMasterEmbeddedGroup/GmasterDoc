第三步：安装 STM32CubeMX

它是硬件配置工具：图形化完成引脚、时钟、外设配置并生成初始化代码，再交由 VS Code 继续开发。

步骤操作
1 下载 官网 st.com/development-tools/stm32cubemx；本课程用 6.12.1，直链见下
2 解压 zip 约 613 MB，解压后得到 SetupSTM32CubeMX-6.12.1-Win.exe
3 安装 运行安装程序，接受协议。安装路径必须纯英文、无空格
4 启动 首次启动会提示登录 myST 账号，免费注册，用于下载固件包

安装包直链（6.12.1）： SetupSTM32CubeMX-6.12.1-Win.zip

Java 依赖：CubeMX 依赖 Java 运行环境。 如果启动时报"找不到 JVM"，安装 Eclipse Temurin JDK 17， 并确认环境变量 JAVA_HOME 指向它。
