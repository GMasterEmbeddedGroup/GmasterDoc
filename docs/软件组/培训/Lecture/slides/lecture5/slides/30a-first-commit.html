第一次提交的完整过程

跟踪一个新文件需要经历“未跟踪、已暂存、已提交”三个状态。每一步都可以用 status 验证。

$ git init -b main
Initialized empty Git repository ...

$ git status --short
?? main.c

$ git add main.c
$ git status --short
A main.c

$ git commit -m "add hello program"
[main (root-commit) a1b2c3d] add hello program

状态怎样变化

?? 未跟踪：文件存在于工作区，Git 还没有把它纳入历史。

A 已暂存：当前文件内容进入下一次提交清单；继续编辑后可能同时出现暂存和未暂存修改。

提交完成：Git 创建第一个提交，main 指向它。文件仍留在工作区，只是当前内容与提交一致。

最后检查：git status 应显示 working tree clean。

VS Code 对应位置：源代码管理面板中的 Changes 是工作区修改，Staged Changes 是暂存区，提交按钮相当于 git commit。
