13定义 int a[] = {2, 4, 6, 8, 10};
sizeof(a) / sizeof(a[0]) 的值为？

查看答案与解析
5。在数组定义所在作用域中，用整个数组的大小除以一个元素的大小，得到元素个数。

14定义 char s[] = "GPIO";，sizeof(s) 的值为多少字节？

查看答案与解析
5 字节。4 个可见字符加上末尾的空字符 \0。

15已定义 void change(int x) { x = 10; }
调用 int n = 3; change(n); 后，n 的值为？

查看答案与解析
3。形参 x 接收 n 的值的副本。修改 x 不会改变调用方的 n。
