while 与 do-while 的组成部分

两者只差一点：条件在循环体之前还是之后判断。

while：先判断条件

while (!sample_ready) {
    /* 条件不成立时，循环体一次也不执行 */
}

do-while：先执行一次

do {
    /* 循环体至少执行一次 */
} while (!sample_ready);   /* 结尾的分号不能漏 */
  1. 条件表达式：与 if 相同，0 为假、非 0 为真；为假时结束循环。
  2. 循环体：花括号块或单条语句。计数变量要在进入循环前初始化、在循环体里更新，否则容易变成死循环。
do-while 至少执行一次：条件在循环体之后判断，适合「先做一次再看结果」的场合；结尾的分号不能漏。
