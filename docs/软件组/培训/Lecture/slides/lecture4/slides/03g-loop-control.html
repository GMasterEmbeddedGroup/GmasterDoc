break 与 continue 的作用范围

break 结束整个循环，continue 只结束本轮，进入下一轮。

break：跳出循环

for (int i = 0; i < n; ++i) {
    if (frame[i] == 0xAA) break;
    payload[len++] = frame[i];
}

continue：跳过本轮

for (int i = 0; i < n; ++i) {
    if (frame[i] == 0xFF) continue;
    payload[len++] = frame[i];
}
for (int i = 0; i < frame_len; ++i) {
    if (frame[i] == 0xFF) continue;   /* 分隔字节：跳过本轮 */
    if (frame[i] == 0xAA) break;      /* 帧头：结束查找 */
    payload[len++] = frame[i];
}
只看最内层：两者都作用于最近的一层循环；break 在 switch 里跳出的是 switch，而不是外层循环。需要跳出多层时，把条件提到外层，或封装成函数用 return，比 goto 好读。
