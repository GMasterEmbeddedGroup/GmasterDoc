# 培训课程（Lecture 系列）

面向新队员的系列课程：从「电控组做什么、工具怎么装、第一个工程怎么跑通」开始，逐步进入 C 语言基础与嵌入式开发。

每节课都配有**可交互课件**（点击章节可跳转、折叠问答、选项卡、随堂小测）与**课后作业**。课件是纯静态页面，打开页面后可按 <kbd>F</kbd> 全屏播放。

## 学习建议

1. **课件要跟着动手**：每一章的「动手练习」都当场敲一遍，只看不写记不住；
2. **报错信息要读完整**：编译器已经把文件和行号告诉你了，看不懂再问；
3. **作业按周清**：编译不过的作业等于没交，卡住就在群里把「代码 + 报错」一起发出来；
4. **课件大纲在每页开头**：复习时直接跳到对应章节即可，不必从头看。
