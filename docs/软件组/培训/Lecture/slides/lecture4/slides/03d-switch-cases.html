switch 的两个实例

左边每个分支都主动结束，右边漏写 break，执行会继续往下贯穿。

每个分支都 break

switch (cmd) {
case CMD_STOP:
case CMD_RESET:        /* 两个标签共用一段代码 */
    motor_stop();
    break;
default:
    log_unknown(cmd);  /* 其余情况 */
    break;
}

漏写 break 的后果

switch (cmd) {
case CMD_RUN:
    motor_start();     /* 漏写 break */
case CMD_STOP:
    motor_stop();      /* 执行 CMD_RUN 时
                          会顺带执行这里 */
    break;
}
读代码时先找 break：两个 case 挨着写表示共用同一段代码（如左图的 CMD_STOP 与 CMD_RESET），这是有意的；漏写 break 则是往下贯穿，属于要立刻修掉的错误。
