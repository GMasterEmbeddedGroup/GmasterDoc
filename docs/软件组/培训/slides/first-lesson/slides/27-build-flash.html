编译与烧录

工程生成后，先编译通过，再烧录到芯片运行。

方式一VS Code

用 CMake 插件选择工具链，再选预设（Debug 或 Release），然后 Configure、Build。产物在 build/ 下。

方式二命令行

cmake --preset Debug，再 cmake --build build/Debug。预设名称以工程里的配置为准。

方式三ST 官方扩展

STM32 VS Code Extension 可以直接构建并烧录，配置写在工程里，点一下按钮即可。

烧录前三件事：烧录器线序正确（绿黄黑红，对应 3V3、GND、CLK、DIO），目标板已经供电，并且选对了烧录器类型 （ST-Link 或无线烧录器）。

无论采用哪种方式，最终都是把 .elf 或 .hex 写入 Flash。 当 LED 按代码预期闪烁，说明编辑、构建、烧录、运行整条链路已经打通。
