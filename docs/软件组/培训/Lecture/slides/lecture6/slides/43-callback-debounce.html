回调函数与非阻塞消抖

ISR 只记录事件和时间，主循环等待电平稳定后再执行业务动作。

static volatile uint32_t key_tick;

void HAL_GPIO_EXTI_Callback(uint16_t pin)
{
  if (pin == GPIO_PIN_0)
    key_tick = HAL_GetTick();
}
if (key_tick &&
    HAL_GetTick()-key_tick >= 20) {
  key_tick = 0;
  if (HAL_GPIO_ReadPin(GPIOA,GPIO_PIN_0)==0)
    HAL_GPIO_TogglePin(GPIOC,GPIO_PIN_13);
}
为什么不延时ISR 内长时间等待会推迟其他中断，系统节拍也可能受影响。
为什么再读取20 ms 后确认按键仍为低，才能把抖动边沿与真实按下区分开。
volatile 要求编译器每次读取共享变量，但不能自动保证多步操作的原子性。
