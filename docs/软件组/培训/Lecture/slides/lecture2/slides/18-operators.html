运算符含义例子结果
+ - *加、减、乘3 * 412
/除（两边都是整数时做整除）7 / 23
%取余，只能用于整数7 % 21

取余最常用于判断奇偶（n % 2）和环形计数（index % 8）。

运算符含义例子结果
==等于3 == 31（真）
!=不等于3 != 30（假）
> < >= <=大于 / 小于 / 不小于 / 不大于5 >= 41（真）

C 语言里没有真正的布尔类型（C99 的 _Bool 除外）：比较的结果是整数 1 表示真、0 表示假。

运算符含义说明
&&逻辑与两边都为真才为真；左边为假时右边不再计算（短路）
||逻辑或任一边为真即为真；左边为真时右边不再计算
!逻辑非!0 得 1，!3 得 0（非 0 即为真）

短路特性很有用：if (p != NULL && p->value > 0) 可以避免野指针（这一写法在 GSRL 里到处都有）。

运算符等价写法说明
=—把右边的值写进左边：speed = 100;
+= -= *= /= %=a = a + ba += b; 是简写，读起来更短也更少出错

注意 = 是赋值，== 才是比较。这两者写错编译器通常不报错，是经典 bug。

写法含义使用后
i++先用 i 的值，再加 1int i = 3; n = i++; → n = 3, i = 4
++i先加 1，再用 i 的值int i = 3; n = ++i; → n = 4, i = 4
i-- / --i同理，减 1一般用于循环计数

单独写成一行 i++; 时两者没有区别。不要在同一行里对同一个变量既自增又使用，那是未定义行为。

运算符含义典型用途
&按位与掩码取值、把某一位清 0
|按位或把某一位置 1
^按位异或翻转某一位
~按位取反配合 & 做清零
<< >>左移 / 右移快速乘除 2 的幂、生成位掩码
