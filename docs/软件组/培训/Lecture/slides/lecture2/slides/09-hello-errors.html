五个最常见的入门报错

报错信息不是敌人，它已经告诉了你错在哪一行。点击展开查看原因与解法。

编译器在报错的那一行找不到分号，于是把问题指向了上一行。
解法：顺着报错行往上看一行，给那条语句补上分号。
编译器不认识 printf，只能猜它的参数类型（C99 之后这会变成警告甚至错误）。
解法：在文件开头补上 #include <stdio.h>。
输入法还停在中文状态下写下了 ； ， “ ”（），它们是多字节字符，编译器读不懂。
解法：把报错行的标点重新用英文输入法敲一遍；写代码时保持输入法为英文。
链接器找不到程序入口，常见原因是把 main 拼成了 mian， 或者文件名带后缀错误（保存成了 hello.c.txt）。
解法：确认函数名是 main，并用 ls / 资源管理器确认文件真的叫 hello.c。
编译器一直到文件末尾都没等到该有的 }。
解法：在 VS Code 里把光标移到任意一个 { 或 } 上， 它配对的另一个括号会高亮，逐对检查即可。
