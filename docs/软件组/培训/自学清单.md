# 自学清单

## 重要性说明

- 必修：必须学习和观看的内容，需按课程计划完成观看学习，将设置quiz进行考核，课上会进行讲解和答疑。
- 辅修：建议学习的内容，作为对必修知识的补充，但不设置考核，且课上不进行讲解。
- 选修：可选学习的内容，作为兴趣拓展和深入研究的材料，仅供自我提升。

> **怎么用这份清单**：表格「备注」列里的链接指向战队自编的 [C++ 基础](C++基础/index.md)、[C++ 进阶](C++进阶/index.md)、[嵌入式基础](嵌入式基础/index.md) 等文档 —— 看视频时遇到没讲透的概念，直接回查对应章节即可。
> 文末的「参考文档与手册」章节汇总了各方向公认写得好的外部资料（参考手册、编码规范、在线书、在线工具），按需查阅，不必通读。

## 参考文档与手册

以下资源来自官方或社区，属于各方向公认质量较高的文档、规范与在线工具。它们**不是课程**，不需要从头读到尾，遇到问题按需查阅即可（中文资源优先列出，英文资源在说明里标注）。

### C++ 与编程语言

| 资源 | 形式 | 说明 |
|------|------|------|
| [LearnCpp](https://www.learncpp.com/) | 在线教程（英文） | 公认最系统的 C++ 教程，从编译链接讲到类与模板，每章配练习；想补基础漏洞时从目录挑章节看 |
| [现代 C++ 教程（欧长坤）](https://changkun.de/modern-cpp/zh-cn/00-preface/) | 在线书 | 中文，几小时就能速览 C++11 到 C++26 的新特性，理解 auto、智能指针、右值引用等概念的最佳入门 |
| [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines) | 规范（英文） | C++ 之父参与维护的现代 C++ 最佳实践，写代码拿不准“该不该用裸指针”时按章节翻 |
| [Google C++ Style Guide](https://google.github.io/styleguide/cppguide.html) | 规范（英文） | 工业界广泛采用的命名与文件组织约定，理解“为什么这样写” |
| [C++ 中文周刊](https://github.com/wanghenshui/cppweeklynews) | 周刊 | 每期几篇现代 C++ 文章，长期跟进语言演进 |
| [cplusplus.com 参考](https://cplusplus.com/reference/) | 参考（英文） | 比 cppreference 简洁，适合快速查函数签名与用法示例 |
| [Compiler Explorer](https://godbolt.org/) | 在线工具 | 把代码实时编译成汇编，对比 `-O0` / `-O2` 差异，验证“这样写会不会更慢” |
| [C++ Insights](https://cppinsights.io/) | 在线工具 | 展开 auto、lambda、范围 for 等语法糖的真实形态，配合 [lambda表达式](C++进阶/lambda表达式.md) 看效果很好 |
| [Quick C++ Benchmark](https://quick-bench.com/) | 在线工具 | 在线微基准测试，比较两种写法的实际开销 |
