类型转换：整数除法是最经典的坑

不同类型混在一起运算时，编译器会先「统一类型」再计算。这一步往往是新手最容易出错的地方。

cast.c看得见的差异
#include <stdio.h>

int main(void)
{
    printf("%d\n", 5 / 2);            // 两边都是整数 → 整除，结果是 2
    printf("%.2f\n", 5.0 / 2);        // 有一个是浮点 → 结果是 2.50
    printf("%.2f\n", (float)5 / 2);   // 强制转换：(float)5 变成 5.0
    printf("%d\n", (int)3.99);        // 显式转换：截断成 3
    return 0;
}
写除法前先问一句：「我希望结果是小数吗？」如果是，两个操作数里至少要有一个是浮点，否则结果会被悄悄截断。
隐式转换
小范围类型自动转成大范围类型（int → double）是安全的；反方向转可能丢数据，编译器通常只给警告。
显式转换
写法是 (目标类型)表达式，只改变这一次运算的类型，不改变变量本身的类型。
浮点数比较
不要写 if (a == 0.1)；浮点有精度误差，应写成 if (fabs(a - 0.1) < 1e-6)。
