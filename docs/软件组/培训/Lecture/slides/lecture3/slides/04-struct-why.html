结构体的定义与用途

定义：结构体是用户定义的数据类型，它把多个可能不同类型的变量组合成一个整体；其中每个变量叫作“成员”。

不用结构体：关系全靠下标

int motor_id[4];
float motor_speed[4];
float motor_current[4];

三个数组靠相同下标维持关系。字段越多，越容易把不同电机的数据配错。

使用结构体：一条记录就是一个对象

Motor motors[4];
motors[0].speed = 120.0f;
motors[0].current = 3.2f;

每个元素就是一台电机。传参、复制和扩展字段都围绕同一个对象进行。

记忆点：结构体类型像一张空白档案卡，成员是卡上的栏目，结构体变量是一张已经填写的卡。
