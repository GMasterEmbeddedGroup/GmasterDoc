动手练习：输入 → 计算 → 输出

这三个练习把本讲的所有知识点串起来，建议当场写完前两个。

练习 1四则运算

输入两个整数，输出它们的和、差、积、商。
提示：商要用浮点输出，注意整除陷阱；除数不能为 0。
进阶：把 %d 换成 %x，观察两个数的十六进制形式。

练习 2圆的周长与面积

输入半径（浮点），输出周长与面积，保留两位小数。
提示：用 double 与 3.1415926， 输出用 %.2f；想想为什么不用 float。

练习 3无循环打印二进制

输入一个 0~255 的整数，输出它的十六进制与二进制。
提示：十六进制直接 %x；二进制先手工写出 8 位， 再用位运算 (x >> n) & 1 逐位打印（循环下节课讲）。
