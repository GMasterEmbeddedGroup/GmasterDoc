程序的基本结构与书写规范

编译器不关心空格和换行，但人读代码时全靠它们。规范不是形式主义，是让别人（和未来的你）能看懂。

一个 C 程序由什么组成

  • 预处理指令：#include、#define，行尾不加分号
  • 函数：程序的基本单位，必须有且只有一个 main
  • 语句：函数体里的一行操作，以分号结尾
  • 注释：// 与 /* */，写给人看，编译时会被删掉

必须遵守的硬规则

  • 区分大小写：main 与 Main 是两个名字
  • 英文半角符号：分号写 ; 不是 ；
  • 括号成对：{ }、( )、" " 一起写
  • 先声明后使用：变量、函数都要先出现在使用位置之前

推荐写法

一个花括号一层缩进（4 空格）；运算符两侧留空格；变量名用小写下划线 motor_speed。

注释怎么写

写「为什么这么做」：// 电机最大转速，单位 rpm。
