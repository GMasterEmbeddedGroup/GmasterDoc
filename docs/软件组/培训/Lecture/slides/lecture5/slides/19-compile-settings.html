编译标准、宏与警告选项

把要求挂在目标上，避免用全局命令污染整个工程。

CMakeLists.txt
target_compile_features(app PRIVATE c_std_11)
target_compile_definitions(app PRIVATE APP_VERSION=4)

if(CMAKE_C_COMPILER_ID MATCHES "GNU|Clang")
    target_compile_options(app PRIVATE -Wall -Wextra)
endif()

features

声明需要 C11，CMake 为当前编译器选择合适参数。

definitions

向预处理器提供宏，不要手写 -D。

options

编译器专用选项先判断编译器，避免跨平台失败。
