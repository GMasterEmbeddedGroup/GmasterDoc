Git 实操答案

下面是一条可直接对照的命令链。每个检查命令都放在会改变状态的命令之前或之后。

$ git init -b main
$ git add CMakeLists.txt main.c .gitignore
$ git diff --staged
$ git commit -m "add starter project"

$ git switch -c dev/message
# 修改 main.c 后
$ git status --short
$ git diff
$ git add main.c
$ git diff --staged
$ git commit -m "change greeting message"

结果检查

分支：git branch --show-current 应输出 dev/message。

工作区：git status 应显示 clean，说明没有漏掉仍需提交的修改。

历史：git log --oneline --graph --decorate --all 应显示 main 停在首次提交，dev/message 多一个提交。

撤销暂存测试：修改 main.c 并 add 后运行 git restore --staged main.c，文件修改仍在，但 staged diff 为空。

命令不是背诵题。每一步都用 status 或 diff 验证状态，就能从输出推导下一步。
